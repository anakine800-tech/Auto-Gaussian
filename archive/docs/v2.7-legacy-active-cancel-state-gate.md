# Auto-G16 v2.7 legacy active-cancel state gate

## Scope

This maintenance patch narrows only the existing `legacy_rtwin_pbs` active
cancellation owner. It does not add a direct backend effect owner, direct
transport, direct qdel, server-file cleanup, retry, scientific acceptance,
deployment or live authorization. Direct W7 remains absent and direct
cancellation remains production-blocked.

## Exact pre-effect rule

The existing exact approval, exact job ID, attempt binding, immutable intent,
append-only local state, at-most-once qdel and no-automatic-retry rules remain
in force. After intent consumption, active cancellation performs two read-only
`qstat -f <exact-job-id>` observations. The second is immediately before the
effect boundary. These are two explicit prechecks, not invocation through the
automatic read-only retry helper. Each observation is eligible only when the
successful output contains exactly one matching `Job Id`, exactly one matching
`Job_Name`, and exactly one single-token `job_state` whose value is `Q` or `R`.

`H`, `E`, every other state token, lowercase or Unicode lookalikes, missing or
duplicate fields, multiple records, job ID/name conflict, explicit Unknown Job
Id, transport ambiguity and state/identity drift all issue zero qdel. The
intent remains consumed, so none of these outcomes grants an automatic resend.
Local completed, failed, interrupted, stale or scheduler-zombie evidence also
stops before network access; it is never handed to or absorbed from the
separate `cleanup-zombie` owner.

`reconcile-cancellation` uses the same strict parser but remains read-only. It
reports `active` only for exact `Q`/`R`, `absent` only for explicit Unknown Job
Id, and `unknown` for every other state or uncertainty.

## Local journal path boundary

Active cancellation and reconciliation now reject any symlink already present
in the supplied local job-directory ancestry before reading or publishing the
cancellation journal. Immutable intent/receipt no-clobber behavior is
unchanged. This bounded patch does not convert the legacy path-based job-state
and immutable-publication helpers into a retained descriptor-relative owner;
a hostile concurrent ancestor rename/replacement between checks and later
path-based operations remains a residual P2 TOCTOU limitation. Closing that
race requires a separately reviewed local journal-owner refactor and must not
be claimed from this patch.

## Offline evidence boundary

Synthetic hostile tests cover the complete accepted/non-accepted state matrix,
strict record cardinality and spelling, whitespace/token boundaries, identity
conflict, terminal and zombie local evidence, pre-qdel drift, Unknown Job Id
race, transport ambiguity, symlink ancestry, one-shot concurrency, receipt
failure and uncertain qdel outcome. All command execution is mocked; no
network, SSH, RTwin, PBS, Gaussian, qdel, deployment or Skill synchronization
is performed.
