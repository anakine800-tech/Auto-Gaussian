# Auto-G16 v3 Non-Goals

The following are not current development targets:

- v2 runtime compatibility;
- a hash lineage forest;
- an owner receipt forest;
- same-process hostile-code defense;
- a generic compatibility capsule framework;
- a generic plugin framework;
- multi-user authentication or service operation;
- a server daemon;
- a GUI;
- an ML scheduler;
- arbitrary-command transport;
- an excited-state workflow;
- MECP;
- microkinetics;
- an unrestricted generic workflow language.

Adding any item requires a later explicit scope decision; it must not enter v3
as incidental infrastructure.
