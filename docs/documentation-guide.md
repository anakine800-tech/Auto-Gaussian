# Auto-G16 documentation guide

Start with the [project introduction](../README.md) for an overview or the
[v3 index](v3/INDEX.md) for component-specific reading. The
[development handbook](development-handbook.md) describes the development
sequence and validation requirements.

The index separates current rules, frozen technical contracts and dated
historical observations. An archive can still contain an effective technical
contract; its age or location alone does not make it ordinary prose. The
[historical status entry](v3/INDEX.md#historical-status-snapshot-provenance)
explains the archived snapshot's source and reading context.

This guide is navigation and explanation only. It adds no permissions and
does not replace the linked authority sources or reopen historical approvals.
