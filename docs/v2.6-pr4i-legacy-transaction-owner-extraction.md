## Mechanical boundary

`_legacy_transaction_once(args, ...)` remains the compatible legacy entry. It
passes the current parser namespace to the only token-gated CLI factory and
then calls `_execute_legacy_transaction_once(plan, ...)` exactly once. The
private typed plan has closed slots, is frozen after owner construction, and
rejects ordinary construction. The execution owner consumes only that sealed
plan and the existing fixed module owners; it has no `argparse.Namespace`
branch.

The body retains the original stage, ledger/state, runner, command rendering,
call order, exception branches, output and exit codes. No transaction copy was
introduced.

The sole future extension boundary is plan construction. A separately
reviewed sealed-handoff factory could target this same private plan, but PR4I
does not add that factory, expose the plan, accept mappings, or connect PR4F.
`LegacyTransportAdapter.invoke_reserved_once` remains fail closed. This
mechanical extraction neither implements nor authorizes PR4H, deployment,
transport, PBS, Gaussian, a live smoke, merge, or release.
