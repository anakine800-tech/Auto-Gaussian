## 1. 背景与当前状态

### 1.1 触发这批工作的实际情况

某进行中的私有 study 已有一批手工构建、尚未计算的 TS 初猜。

**因此本批开发的首要目标是：让"拿到第一个合格 TS"这件事有工具支撑，而不是靠手工猜几何加盲投 DFT。**

### 1.2 这决定了优先级

手工候选的根本问题是**没有能量信息**：猜测的键长不等于势垒位置。仓库里 `scan` + `scan-peak` 正是为定位势垒做的（`scan-peak` 只取两侧邻点均收敛的严格内部局部极大），而且两侧端点都是已优化的极小点 —— 这是双端类方法（QST2、路径搜索）最需要、通常却拿不到的条件。

所以 P0 的重点是**把已有工具串成可用链路**，不是新建通用框架。

### 1.3 复审结论对原方案的修正

第三方复审确认总体方向成立，但指出若干需在开发前修正的问题。规划侧接受其中绝大部分。对开发影响最大的四条：

| 复审结论 | 对开发的直接影响 |
|---|---|
| xTB 结果用于生成、排序和诊断，不应决定候选能否进入 DFT | G0 从"门禁"降级为"诊断＋优先级"，硬拒绝只保留输入完整性与几何损坏 |
| 原方案的反应向量定义漏了成键与断键的相对符号，共享原子上的贡献可能互相抵消，外层绝对值消不掉 | 必须改用内坐标投影实现（见 T-E） |
| 选择性汇总必须使用共同参考态，并正确处理重复结构、对称等价与前体平衡 | 需先审计 `profile` / `ensemble` / `dedup` 的实际行为（见 T-A） |
| 固定单一反应核心做构象搜索本身就是覆盖限制 | 多核心种子列入 P1，不在 P0 |

此外复审指出原方案"没有双端初猜路线"的表述有误：**QST2 本身就是使用两端结构的 STQN 方法**，真正缺的是"显式生成路径图像并从中提取候选"。

## 3. P0 工单规格

### T-A 现状审计（**先做，不改代码**）

**目标**：后面几个工单的范围取决于仓库现状，规划侧无法直接读取代码，由开发对话先行核实。

**需要回答的问题：**

1. `profile` 的参考态处理：跨不同前体的反应分支，自由能如何取参考？是否存在把各自前体的局部能垒直接混加的代码路径？T82 的一致性检查覆盖到哪一层？
2. `ensemble` / `dedup` 的计数语义：对称等价结构、以及多次收敛到同一个驻点，是否会被重复计入系综权重？有没有真实简并因子的位置？
3. `scan` 现状：xTB 一维弛豫扫描 → `scan-peak` → TS 输入准备，这条链路哪一段已通、哪一段需要人工搬运？
4. QST2：对两个**独立优化**的极小点，仓库有没有原子顺序/取向对齐的工具？现有 QST2 校验在原子顺序不一致时的行为是什么？
5. 父 chk 力常数：模板用的是 `RCFC` 还是 `ReadFC` 语义？是否强制绑定到由频率计算生成的 chk？坐标取向核对在哪一步？
6. `facts` / manifest 里有没有可直接扩展的候选来源字段位，还是需要新 schema？
7. 扫描逐点几何能否直接喂给 `topology` 做沿程比较？

**产出**：审计报告一份，附代码位置引用。**不改代码，不提交计算。**

**验收**：监督方确认七个问题都有明确答复（"没有"也是答复）。

### T-B 候选与来源台账

**目标**：让每个初猜候选可以回答"从哪来、试过什么、失败在哪"，并让"某通道已尝试未找到"有证据支撑而不是空白。

**范围**：

候选记录字段（名称可按仓库既有命名调整）：

| 字段 | 内容 |
|---|---|
| `guess_origin` | scan / qst / template_transform / path_search / manual / literature |
| `parent` | 父结构：Attempt 编号，或文件路径加 SHA-256 |
| `transform` | 几何变换的类型与参数（轴原子、角度、移动原子集） |
| `target_channel` | 目标通道 |
| `assigned_channel` | 实际判定的通道 |
| `diagnosis` | 诊断结果与数值（见 T-E） |
| `outcome` | 通过验收 / 落入其他通道 / 收敛到极小点 / 优化失败 / 多个虚频 |
| `literature_ref` | 文献来源的 DOI 与 SI 位置 |

归属状态必须三分，不可合并：**目标通道**、**暂定归属**（已判定但未经 DFT 验收）、**已验证归属**。

按通道汇总的尝试台账：来源、诊断结果、DFT 结果、日志位置。台账是覆盖状态"已尝试未找到"的唯一依据。

**不做**：
- 不新增自动提交路径。
- 不改写既有 `facts` 字节（沿用内容相同保留原字节的现行规则）。
- 不推断化学含义；通道的化学定义由人给出。

**验证**：非研究 study 上跑通一遍记录→查询→汇总。

**备注**：已有一批手工候选尚未登记。本工单完成后由负责人决定是否补登记；补登记属执行任务，不在本工单范围。

### T-C 扫描到 TS 的衔接

**范围以 T-A 第 3 问的答复为准。** 以下是目标状态：

1. 沿人指定的内坐标做 xTB 一维弛豫扫描，解析逐点几何、能量与收敛状态。

**范围以 T-A 第 4 问的答复为准。** 目标状态：

### T-E G0 诊断与提交排序（**按复审口径重写，不是原方案的门禁**）

**定位改变**：原方案把 G0 写成能拒绝候选进入 DFT 的门禁。复审指出初猜不是驻点、xTB 与 DFT 在 TS 区域曲率可能不同，低层无虚频不能否定一个 DFT 初猜。**本工单只保留两类硬拒绝，其余一律是标记和优先级信号。**

**硬拒绝（仅此两类）**：

| 检查 | 说明 |
|---|---|
| 输入完整性 | 原子数、原子顺序、电荷、多重度与**当前计算子任务**一致 |
| 几何损坏 | 键长明显非物理、原子重叠 |

**第一条必须按子任务判定，不是按 study 判定。** 比较"含一分子显式溶剂"与"不含"的机理时原子数本来就不同，按 study 统一会直接误杀。

**标记／降优先级（不影响能否提交）**：

| 检查 | 处理 |
|---|---|
| 普通空间冲突 | 优先尝试受限松弛 |
| 形成/断裂键距离超出人设窗口 | 标记，人审 |
| 立体标签与目标通道不符 | 改记为实际所属通道的候选 |
| xTB 无虚频 / 虚频不匹配 | 标记、降优先级或转直接 DFT |
| xTB 高能、端点塌缩 | 记录**低层路线失败**，不排除该通道 |
| 标签不能唯一判定 | 暂存待判，不强行归类 |

**反应坐标投影的实现要求（原方案此处有错，必须按新规格实现）**：

原方案定义为"对每根形成或断裂的键，在两端原子上放方向相反的单位位移"，**没有规定哪根键伸长、哪根缩短**。对共享原子的情形（例如质子转移中 H 同时属于断裂键和形成键），若两根键按同一规则机械相加，共享原子上的贡献会互相抵消，而公式外层的绝对值只能消除整体符号，修不了这个问题。

改为内坐标投影：

```latex
\delta c = B q
```

其中 `c` 是成断键距离及必要角度构成的内坐标集合，`B` 是这些内坐标对笛卡尔坐标的导数（Wilson B 矩阵），`q` 是振动模式的笛卡尔位移。直接读出一个模式如何改变各反应内坐标，并**显式规定断裂键应伸长、形成键应缩短**。

其余实现要求：
- **检查所有相关负模式，不只取最大虚频。** 最负的模式可能是无关扭转。
- 若另行计算投影分数，必须统一质量加权约定并说明模式归一化。
- **默认不对每个候选计算完整 xTB Hessian。** 数值 Hessian 成本在候选量大时不可忽略；是否计算由调用方显式开启。

**产出**：诊断报告 + 建议提交顺序。顺序建议只是排序，提交与否由负责人决定。

**不做**：
- 不设自动拒绝阈值。规划侧曾提出 0.5 的模式重叠阈值，**该数值不进入本期实现**，留作后续按用途校准的候选值。
- 不替代 DFT 验收。

**验证**：非研究 study；必须含一个共享原子的质子转移夹具，用于验证符号约定没有抵消。

### T-X 结论口径修订（文档与卡片，不是代码）

以下是表述和判据的修正，不涉及新功能，但会改变报告内容，须与上面的工单同批审阅：

1. **共同参考态。** 不同前体的局部能垒不得直接混加。举例：前体 A 自由能为 0、局部垒 10；前体 B 自由能为 3、局部垒 9 —— 共同参考下是 10 和 12，不是 10 和 9。系综加权前必须核对共同参考态、标准态、热修正、计量/浓度项，以及前体互变是否足够快。
2. **三数报告。** 选择性同时报"仅用最低 TS 的 ΔΔG‡ / 系综的 ΔΔG‡ / 两者之差"，使构象采样对结论的影响可见。
3. **简并因子。** 系综求和中的简并只能是真实对称简并，**不得把重复找到同一个 TS 的次数当作简并**。
4. **覆盖状态词表。** "系综已收敛"改为"**在声明的通道范围与采样预算内稳定**"。通道状态增加"待确认通道"（采样中新发现、待人判断）与"低置信度排除"。
5. **IRC 政策。** 改为按**各产物分支内部的重要性**和结构新颖性判断，不按全局权重。高选择性反应中次要产物的全部 TS 全局权重都可能很小，但它们决定 er 的分母。必做的情形：引入新的成断键集合或质子转移方式、引入新活化模式、在所属分支内贡献显著、改变最低 TS 排名或明显改变预测 ee/dr、模式或产物归属存在歧义。IRC 两端仍须继续优化确认极小点，不得把有限步数的路径终点直接当作稳定物种。
6. **删除一处推断。** 约束采样中出现"通道泄漏"**不证明真实体系中两条通道快速互变** —— 它发生在带约束、带采样偏置的低层势面上，不能用于支持 Curtin–Hammett 条件。原方案 L3 一节的相关表述须删改。
7. **刚性变换全部冲突**只说明该组模板和变换失败，不构成通道排除依据。
8. **低层端点塌缩**停止的是该条低层路线，通道应转入其他方法。
9. **数据模型需允许**"一个 TS 的产物分支尚不能唯一确定"这一状态（TS 后分岔）。本期只需能标记"简单 TS 能垒比不适用"，**不开发轨迹计算**。

## 4. P1 工单规格（第一个 TS 验收之后）

### T-F TS 构象扩展闭环

种子 TS → 约束采样 → 去重与多样性筛选 → DFT 重优化 → 频率/IRC 验收。

**约束分三类**，不是原方案的"最小集 vs 扩展集"两套机械对跑：

| 类别 | 内容 |
|---|---|
| 反应核心必要约束 | 维持反应核心所必需。**不等于只约束成断键距离** —— 亲核取代可能需要维持局部进攻方向，质子转移需要保持供体-H-受体几何，多键环化需要保持多个接触点及相对取向 |
| 当前通道保持约束 | 定义该通道的关键接触 |
| 可轮换释放的环境接触 | 催化剂外围氢键等，不应全部锁死，否则替代结合方式进不来 |

先小规模采样检查核心是否保持，再按需增加约束。**不要求每个通道都跑满两套。**

**约束能处理（实现要点）**：CREST 的约束通常参与所有 xTB 计算，包括单点。正确的重新排序方法是**在候选的同一几何上另做一次去掉约束势的单点**，而不是先做无约束优化。同时必须检查 CREST 内部筛选是否已经用带约束能丢弃了候选 —— 事后扣能量救不回已丢弃的结构。

**能量窗口**：规划侧曾提 6 kcal/mol。该值只能作为试运行窗口，**不构成"不会漏掉低能 DFT TS"的保证**。送 DFT 时应兼顾低能、结构簇、接触模式和少量窗口外代表。

DFT 层需再去重一次（Kabsch RMSD，保留极性氢），多个低层构象常收敛到同一个 DFT TS。

### T-G 模板几何操作

原方案的 C1 反射 / C2 绕键旋转 / C3 片段转动**合并为一个"保留指定立体信息的模板几何操作"**，反射只是其中一种受限操作。

**默认操作改为正规刚体旋转**：通过反应中心选择底物局部平面内的一条轴旋转 180°，可翻转呈现的面同时保留片段原有手性；随后采样绕进攻轴的方位角。

反射若保留为可选操作，必须检查：会反转移动片段的**全部**手性（中心、轴、面、螺旋），不能只查四面体中心；移动片段含多个反应中心时可能同时改变多个面；分子内或共价催化须检查移动片段与固定部分的**所有**连接。TS 部分成键区从 XYZ 猜键再分配 R/S 不稳定，须依赖确认过的原子映射和参考分子图，并允许"暂不能唯一标注"。

多点锚定或分子内环化更适合模板约束重建或约束距离几何，不适合刚性变换。

### T-H 多核心种子覆盖

不同 TS 构象可能具有不同的活性键长。固定一个种子的核心几何做外围采样，无法覆盖另一种核心几何。至少提供一条补充探索路径：从另一独立来源取核心种子、对关键活性键长作少量合理扰动、或从不同反应物构象重新搜索路径。

## 5. P2（暂不开发，按失败类型再定）

## 7. 验证要求（适用于全部工单）

1. **合并前以非研究 study 做真实验证。** 涉及证据清单、远程命令、提交、状态、取回的改动尤其不可豁免。
2. **离线测试不等于真实验证**，真实验证不等于科学验收。三者在工单和 PR 里分别陈述。
3. **失败场景必须有夹具**：共享原子的质子转移（T-E）、扫描中途构象跳变（T-C）、原子映射对称歧义（T-D）、不同化学计量的物种比较（T-E 硬拒绝第一条）。
4. **不得用私有 study 的真实结构作测试夹具。** 用合成夹具或已发表体系。
