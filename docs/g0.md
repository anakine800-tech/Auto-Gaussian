# G0 本地候选诊断（T137 / T138）

`ag g0` 在 DFT 前检查 catalog 中的初猜候选。只把输入完整性不符或极端几何损坏
记为 `rejected`，并返回非零退出码；它不接入 prepare/submit，不改变提交资格。
默认只打印，不创建或修改 study 中的文件，也不运行任何计算、访问远程或修改 facts/manifest。

固定声明：**G0 是本地诊断，不是门禁；不替代 DFT 验收；clean 只表示未发现问题。**
**顺序只是建议，提交与否由负责人决定。**

## 命令

```sh
ag g0 '<STUDY>' --object '<OBJECT>' --candidate '<CANDIDATE>' --json
ag g0 '<STUDY>' --object '<OBJECT>' --all --windows analyses/windows.json
ag g0 '<STUDY>' --object '<OBJECT>' --channel '<CHANNEL>' --window 1-5:1.8:2.6
ag g0 '<STUDY>' --object '<OBJECT>' --candidate '<CANDIDATE>' \
  --modes-attempt '<FREQ_ATTEMPT>' --windows analyses/windows.json \
  --reaction-coordinate distance:3-7:forming --json
ag g0 '<STUDY>' --object '<OBJECT>' --candidate '<CANDIDATE>' \
  --reference-attempt '<ATTEMPT>' \
  --stereo-json '<LABELS_JSON>' --stereo-attempt '<LABEL_ATTEMPT>' --expected-label 'C2:R'
ag g0 '<SYNTHETIC_STUDY>' --object '<OBJECT>' --all --record --dry-run
```

`--candidate`、`--all`、`--channel` 三选一。`--reference-attempt`、`--modes-attempt` 和立体参数只用于单个候选，
三项立体参数必须同时给出。`--window`、`--reaction-coordinate` 可重复。`--dry-run`、`--upgrade-catalog` 必须与
`--record` 同用。退出码：0 为诊断完成且无 rejected，1 为存在 rejected 或输入错误，
2 为批次存在局部频率分段歧义、记录失败或文件访问错误；局部歧义优先于 rejected 的退出码 1。
其余输入/数据错误只有 `error`，不会伪装成候选 rejected。记录失败时仍输出已完成的诊断报告和 `record.error`。

## 完整性和来源

候选只读 `catalog/candidates/<sha256>.xyz`，重新核对登记哈希。哈希不符属于数据损坏，
直接报错，须人工处理；不修复存档、不给诊断结论。

四项检查均给出 `pass / reject / unchecked` 和依据：

| 字段 | 核对内容 |
| --- | --- |
| `atom_count_and_formula` | 候选组成、原子数对照所属对象的 `expected.formula`；沿用 catalog 的 Hill 组成格式 |
| `atom_order` | 候选与参考 Attempt 的元素序列；默认 `parent.attempt`，单个候选可显式指定参考 |
| `charge` | 对象 `expected.charge` 与参考 manifest 的电荷；与候选组成、多重度做电子奇偶核对 |
| `multiplicity` | 对象 `multiplicity` 与参考 manifest 的多重度；同一电子奇偶核对 |

不同对象各用自己的期望值，不能按 study 统一组成。期望 `unset / unknown`、缺参考或
参考缺对应字段时记 unchecked，加入标记；已能确认的不一致仍优先记 reject。
XYZ 不携带电荷、多重度。电子数检查复用 `gaussian_input.check_electrons`，联合条件失败在
charge 和 multiplicity 两项均注明，不擅自把错误归给其中一个值。

参考电子态复用 `catalog_v2.manifest_info`；Gaussian 几何来自 manifest，QST 元素序列取第一段；
xTB/CREST 取声明的输入 XYZ 并核对大小和哈希，系综取第一帧。报告保存参考 manifest 哈希与
几何指针或输入哈希。**只比较元素序列；同种元素原子互换无法检出，原子映射仍需人审。**

## 三个固定几何判据

半径取 RDKit 周期表，成键状态逐对复用 `irc_compare._pairs`；单位为 Å，原子编号从 1 开始。
三个数固定在代码中，不开放参数：

1. 任意原子对距离 **< 0.5 Å**：几何损坏，reject。
2. 任意原子对距离 **< 0.5 × 共价半径之和**：几何损坏，reject。
3. 两个重原子在 `_pairs` 中**不是 bonded**，且距离 **< 0.75 × 范德华半径之和**，
   并且没有被本候选的适用距离窗口或 distance 类反应坐标声明为反应原子对：普通冲突，flag。uncertain 也属于不是 bonded。
   提示先核对是否为未声明的反应中心；仅确认普通空间冲突后，再考虑保持反应坐标的受限松弛。

等于阈值不触发该项；每对列原子、元素、距离、成键状态及阈值。
适用距离窗口或 distance 类反应坐标声明的原子对不标记普通冲突，单列于 `geometry.reaction_center_pairs`，
包含原子编号、元素、距离和成键状态；正反编号及重复声明只列一次，成键状态和距离不影响列入。
这些原子对有窗口时仍检查是否超出，并始终接受前两项几何损坏检查；声明反应中心不能豁免硬拒绝。
距离反应坐标来自候选目标通道和命令行补充，即使没有模式数据也适用；angle 类坐标不声明原子对。
未声明的同一对可能同时满足损坏和普通冲突，分别保留事实；损坏中的两个判据合并在该对的 criteria。
需要 RDKit；缺依赖属于运行错误，不是科学拒绝。

## 距离窗口

`--windows` 接受 study 的 `analyses/` 下的文件；相对路径以 study 为基准，绝对路径也必须
在该目录下。路径各级的符号链接、`..` 和越界路径均拒绝。示例：

```json
{
  "channels": {
    "approach-a": [{"atoms": [1, 5], "min": 1.8, "max": 2.6, "label": "形成键 C1–C5"}]
  },
  "all": [{"atoms": [2, 3], "min": 1.0, "max": 3.0, "label": "人工指定距离"}],
  "reaction_coordinates": {
    "approach-a": [{"kind": "distance", "atoms": [1, 5], "role": "forming"}]
  }
}
```

顶层只允许 `channels`、`all`、`reaction_coordinates`，均可省略；其他键报错，防止拼写错误被静默忽略。
`reaction_coordinates` 由 T138 的模式分析读取；所有通道 ID、坐标结构与角色均在读入时校验。
窗口文件由 `g0._windows` 只读取、解析一次；距离窗口和模式分析共用同一份内容与原始字节哈希，
批量中的全部候选也共用这一快照。study 路径或配置中的 study 名都通过 `catalog.resolve_study` 解析。
每个距离窗口为不同的正整数原子编号，有限数值 `0 ≤ min ≤ max`，
label 可省略。每候选依次应用 **all + 目标通道 + 命令行窗口**，不覆盖或自动合并。
`--channel` 可选出历史曾归属该通道的候选，但窗口仍依据候选原登记的 target_channel。
这三种来源中实际适用的窗口声明其反应原子对；其他通道窗口不影响本候选的普通冲突诊断。
闭区间内 pass，外部仅 flag；没有适用窗口记“未设窗口”标记。
报告记录文件相对路径、原始字节 SHA-256，以及每个实际使用的窗口、来源、实测距离和状态。

## 立体标签

读取 `ts_stereo_label.py` 的 `labels.json`，按 `--stereo-attempt` 唯一匹配 `attempts[]`。
消费 `product_configuration`、`product_centers`、`catalyst_centers` 与 `geometry_source`，
不重新计算立体标签。文件路径按普通本地文件路径解析；拒绝符号链接。

先逐原子核对该 Attempt 的输入几何与候选：元素相同，每个 Cartesian 分量之差 ≤ 1e-4 Å；
不做刚体对齐或原子重排。QST3 的立体输入取脚本实际使用的第三段 TS 初猜。
另核对标签所声明的几何来源路径、指针和哈希。脚本默认使用 final 几何，因此若标签来自
`final_input.xyz`，还须确认该几何与候选相同，防止把优化后结构的标签用于不同初猜。
任何来源不匹配均报错，不给结论；格式不符提示停止并人工核对。

| 情况 | 状态/说明 |
| --- | --- |
| 标签与 expected-label 相同 | `match` |
| 标签不同 | `other_channel`，标记“可能属于其他通道” |
| 产物或催化剂中心含 unknown / needs_review，产物中心为空或编号重复无法唯一判定 | `pending`，标记“待判” |
| 未指定立体参数 | `not_requested`，不额外添加标记 |

立体诊断不改归属，也不把匹配当作科学验收；完整配置字符串按脚本原格式精确比较。

## 模式投影

单个候选用 `--modes-attempt` 指定本 study 中精确的、已取回的 Gaussian 频率 Attempt。
批量（`--all` / `--channel`）取每个候选**最新一条 attempt 非空的 candidate-result** 关联的 Attempt，
跳过 diagnosed 等 attempt 为 null 的结果；按 attempt 是否为空选择，不按 outcome 筛选。
没有结果或所有结果的 attempt 都为空时记 `available=false`、“无模式数据”，不新增标记。
选中的最新非空 Attempt 未取回、非 Gaussian 或没有 Freq 段时，也记无模式数据，
不会再退到更早的非空 Attempt。单候选不指定 `--modes-attempt` 也记无模式数据。
需要投影时，显式指定但不可用的 Attempt 报错。批量仅对解析器明确分类的频率分段歧义保留局部错误，
继续诊断其他候选；单候选仍直接报错。facts 不可读、Freq 段异常结束、坏向量或取向无法确认等数据错误，
单个和批量都停止，不把错误降为“无模式数据”；批量不会先记录部分候选。

坐标取 `reaction_coordinates[候选 target_channel]`，再追加可重复的命令行声明；
没有目标通道或对应条目时仍可用命令行补充。全部缺失时记“未声明反应坐标”，不读取频率或做投影。
坐标编号从 1 开始、互不相同且不超过候选原子数。可用格式和角色为：

| kind | atoms | role / 期望符号 |
| --- | --- | --- |
| distance | `[i,j]` | breaking (+1)、forming (−1) |
| angle | `[i,j,k]`，j 为顶点 | increasing (+1)、decreasing (−1)、report（只报告） |

JSON 条目还可带 `label`；命令行例：`--reaction-coordinate angle:1-2-3:increasing`。
只应用目标通道的坐标；其他通道的 distance 不改变本候选的冲突诊断。
角度满足 `|sin θ| < 1e-6` 时无法定义稳定的 B 行，报错“角度坐标退化”。

**约定全文：** 笛卡尔、未质量加权；Gaussian 打印位移 q 重新归一为单位长度
（‖q‖ = 1 Å）；δc = B q；距离变化用 Å，角度变化用弧度并另报度。不旋转、不对齐模式向量。
逐个内坐标使用 Wilson B 导数行，距离行为 `(x_i−x_j)/r` 及其负值；共享原子的贡献不会被按原子相加抵消。
同时比较 σ=±1，先选期望符号吻合数较多者，再按 `σ Σ s_k δc_k` 较大者；完全相等保留 +1。
`|δc| < 1e-3 Å`（距离）或 `< 1e-3 rad`（角度，约 0.0573°）记“≈0，符号不定”，
既不算吻合也不算不吻合；这些是数值零容差，不是科学阈值。角度容差的确认来源与日期见 T138 版本记录。

重叠度 `O = |q·d|/‖d‖`，`d = Σ s_k ∇c_k`，只计有期望符号的坐标；
距离/角度直接使用 Å/rad 原生数值，不额外缩放。d 为零时报告 O=0 并注明无合成方向。
全部虚频都分析，另附最低 3 个非负频率模式作参考；实频不参与标记。
最佳模式在虚频中先按吻合数、再按重叠度选取；同分时保留较低频率，再按原始序号。
重叠度只用于报告和排序，不设阈值。

| 模式标记 | 含义 |
| --- | --- |
| `no_imaginary_mode` | 没有虚频 |
| `multiple_imaginary_modes` | 虚频多于一个 |
| `most_negative_not_best` | 最负模式不是最佳模式 |
| `sign_inconsistent` | 最佳模式未让全部有期望符号的坐标吻合（≈0 不计吻合） |
| `non_stationary_frequencies` | 非驻点，或无法确认驻点 |

驻点只由 facts 中来源能与所读频率段对应、且不晚于该段的已收敛 Opt 建立；
旧 facts 缺来源、来源不符或只有后来的 Opt 时记 `stationarity=unknown`，并加非驻点标记。
同一 Opt Freq 段另确认优化收敛标记在谐振块之前。
候选与频率几何元素序列必须一致，否则报错；只对两套几何做正规旋转的 Kabsch RMSD，
RMSD 大不报错、不拒绝。投影始终使用频率结果自身的几何与位移取向。

文本模式表标星最佳模式，列频率、σ、逐坐标原始/校正 δc、吻合情况与重叠度。
JSON 的 `modes` 含完整 `convention`、`modes[]`、`best_mode`、`flags`、`notes`，另有
`attempt`、`orientation`、`stationarity`、`aligned_rmsd_angstrom`、`geometry_sha256`、
`coordinates_spec`、`coordinate_sources`（窗口相对路径/哈希或命令行）以及 `source`（日志/频率段与哈希）。
几何哈希对应同一取向的 elements、coordinates 紧凑 JSON；日志/频率段哈希对应原始字节。
`delta.value` 是原始 Bq，`corrected_value` 是 σBq；≈0 的 `matches` 和 `corrected_sign` 为 null。
`signed_count` 包含全部声明了期望符号的坐标，`report` 不参与 σ 或重叠度。
结果是诊断，不是 TS 验收；方向判断仍需人审。

## 报告与排序

顶层 `schema=ag-g0/1`，含 `object`、`journal_sha256`、`candidates`、`order`、三种结论的
`counts`、`notice` 和 `order_notice`；显式记录时另有 `record`。

批量发生频率分段歧义时，另有 `errors` 和 `incomplete_notice`，明确“批次未完整完成”。
每个错误含 `candidate`、`object`、`attempt`、`stage=frequency_section`、
`category=ambiguous_frequency_sections`、`reason`，以及安全读取的日志 `source.log`（study 相对路径）
和 `source.log_sha256`（原始字节）；无法确定有效段时不填写 section 或段行范围。
`counts.errors` 为失败数，`counts.selected` 为本次选中数，后者等于 `candidates` 数加 `errors` 数。
成功候选保持完整报告及原排序，`order` 仅含成功项；错误按登记顺序单列，不归入 clean/flagged/rejected。
无局部错误时不添加这些可选字段，原报告结构保持不变。候选哈希、台账、参考身份、路径或窗口错误仍停止整批。

每候选含 `candidate`、`object`、`origin`、`target_channel`、`candidate_sha256`、
`registration_order`（从 1 开始）、`reference`、`integrity`、`geometry`、`windows`、`stereo`、`modes`，
以及 `verdict`、`reject_reasons`、`flags`、`unchecked`、`counts` 和固定说明。
标记和拒绝理由都有 `category`、`message`；完整性另有 field，几何/窗口另有原子和实测值。
`unchecked` 列四项完整性中尚未核对的字段，均计入 flags。
`counts` 保留拒绝理由数、标记数、未核对项数、损坏对数、普通冲突对数、
`reaction_center_pairs`（声明的反应原子对数）、窗口数、超窗数。
五个模式标记以 `mode:` 前缀并入 `flags`，只使候选进入 flagged 组，不产生 rejected。
`counts.g0_flags` 保留 T137 的标记数，`mode_flags` 单列模式标记数，`flags` 为两者之和。

`rejected` 优先于 `flagged`，后者优先于 `clean`。批量分组顺序为 **拒绝 / 有标记 / 无标记**，
组内依次按：有模式数据在前 → 存在符号全部吻合的虚频在前（须有期望符号坐标）→
最佳虚频的重叠度降序（无虚频按 0）→ T137 标记数 `g0_flags` 升序 → 登记顺序。
`order` 给出候选 ID。拒绝组先列便于排查，
不表示建议先提交。默认缺窗口也属于 flagged；clean 允许立体诊断未请求，不能解读为所有科学检查已通过。

## 可选记录

**T140 部署之前，真实研究 study 不使用 `--record`。** 开发验证只使用临时合成 study。
每候选追加 `candidate-result`，`outcome=diagnosed`、`attempt=null`、`assignment={"status":"none","channels":[]}`，
diagnosis 为该候选的报告。按 T131 既有语义，最新 result 的 assignment 为 none；既往归属事件和
目标通道仍保留，不产生新的通道认定。需要保留当前归属展示时，先由负责人理解这一既有台账语义。
诊断中保留本次频率来源；记录本身的 attempt 仍为 null。随后再次批量诊断会跳过这条 diagnosed
结果，继续选择最新一条 attempt 非空的结果，因此记录诊断不会遮住已有频率来源。

单个和批量均走 catalog 的同一 plan、升级、锁及追加路径；批量一次独占锁、一次追加，
全部事件校验完成后才写，任一校验失败整批不写。诊断绑定台账哈希，写入前若对象期望或
台账已变化，拒绝记录，需重新诊断。写入中发生系统 I/O 故障仍沿用 T131 的中断语义：
保留现场、人工检查，不承诺文件系统故障下的事务回滚。

批次只要含局部 `errors`，`--record` 就不进入登记流程，不写任何候选结果事件，也不升级 catalog；
`--dry-run` 同样不生成部分记录计划。成功诊断与错误继续输出，`record.error` 明示未登记，
可单独对成功候选执行诊断/记录。没有强制部分记录选项。

`--dry-run` 只预览；/1 升级需要 `--upgrade-catalog`，失败仍保留诊断输出。
/1 本身不能包含合法候选（首次 candidate 已升级为 /2），因此 /1 的 `--all` 为空报告；
未确认记录时提示升级，空批次确认或预览也不写空事件、不制造升级。

diagnosis 以 UTF-8 JSON 字节计算，最多 64 KiB。超限时标记 `truncated=true`、“已截断”：
先移除实频参考，仍超限则清空坐标声明和逐模式 delta 明细、记录原计数，再裁减 T137 明细列表。
保留每个虚频的序号、频率、σ、吻合数、期望符号总数和重叠度，以及全部原始诊断计数。
若标量文本仍过大，保存候选身份、结论、计数、完整性状态、固定说明与模式摘要。
若连全部虚频摘要都无法放入 64 KiB，明确报记录失败，整批不写。标准输出始终保留完整诊断。

## 与后续任务的分工

G0 不执行 xTB/Gaussian；T138 只读取已有频率，不计算 Hessian，不以模式信息拒绝候选。
xTB 高能、端点塌缩由人登记为候选结果，口径由 T139 卡片说明。这里的实现不代替这些工作。
