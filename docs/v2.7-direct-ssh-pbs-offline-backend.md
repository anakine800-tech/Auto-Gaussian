## Scope and non-authority

This milestone adds one additive, non-executable synthetic transaction for the
single topology Mac controller -> one-hop direct SSH -> `pbs_legacy_v1`. The
transaction has no SSH, subprocess, shell, network, PBS, Gaussian, qsub, qdel,
delete, cleanup, deployment, or live-smoke implementation. It accepts no
command, argv, callback, root, environment, backend selector, or scheduler
selector. A synthetic qsub intent records that a future exact operation would
be required; it is not a command, runner call, scheduler capability, or proof
that a submission occurred.

The transaction consumes the exact milestone-1
`direct_root_mutation_boundary` synthetic transaction and replays the existing
`direct_root_owner_contract` profile `/3`, authorization `/3`, stable evidence,
fresh receipt, workspace, input, resource, task, attempt, and idempotency
bindings. It never reconstructs those owners from caller values. Unsupported,
unknown, old, missing, and foreign objects fail closed. There is no legacy
fallback.

The later W4 fixed helper is deliberately not wired into this offline
synthetic transaction. It closes only the process-isolated physical
project/scratch primitive for W1 POSIX descriptors. This milestone continues
to use its synthetic root transaction; W2 exact-claim adaptation, replay
ingress, transport, qsub, inspect/fetch and live evidence remain blockers.

## Fixed synthetic call chain

1. Accept only the exact current direct-root capability, its identity-bound
   milestone-1 mutation transaction, one immutable transfer model, and the
   exact closed fake transport.
2. Replay the root owner's canonical profile and authorization snapshots and
   join every profile/evidence/receipt/authorization/resource/workspace/task/
   attempt/idempotency/input field into one closed binding.
3. Atomically mark the transaction terminal-for-retry and publish
   `submission_uncertain` in the fake transport before the milestone-1 helper
   can start.
4. Consume the milestone-1 transaction once.
5. Record one fixed immutable in-memory transfer whose bytes match the exact
   authorized basename, SHA-256, and size.
6. Record at most one fixed synthetic qsub intent. No command text or argv is
   ever constructed.
7. Allow typed `inspect` and `fetch` projections that do not mutate the stored
   state. Any failure or unknown outcome leaves `submission_uncertain` and
   cannot be retried automatically.

## Typed operation set

The fake transport recognizes exactly these operations:

- `publish_submission_uncertain`;
- `record_workspace_claim`;
- `transfer_immutable_input`;
- `record_synthetic_qsub_intent`;
- `inspect_read_only`;
- `fetch_read_only`.

There is no generic `execute`, command, callback, argv, environment, root,
backend, scheduler, qdel, delete, or cleanup operation. Unknown enum values,
foreign request types, wrong backend/scheduler, and second mutation attempts
fail closed and never route to legacy.

## Compatibility and frozen boundaries

The merged milestone is additive. It does not modify the legacy facade, factory, raw
owner, `legacy_rtwin_pbs`, legacy root authority, historical schemas, or Skill
tree copies. The repository's named-Skill package supplement maps the new
source and this document, but no deployment or synchronization is performed.
Legacy root bytes remain fixed to `/home/user100/SDL`.

The old `codex/v26-direct-ssh-pbs` branch was used only as read-only
archaeology. No commit or byte was cherry-picked, merged, or rebased.

## Production blockers

Production remains blocked on a physical descriptor-relative mutation helper,
durable cross-process single-use and
uncertain-outcome storage, exact direct-compatible resource/live replay
ingress, a real immutable transport, a real qsub owner, read-only inspect/fetch
transport, independent L3 approval of the eventual production candidate, and
a separately authorized live smoke. Offline tests, packaging, a local commit,
or later CI cannot grant any of those authorities.
