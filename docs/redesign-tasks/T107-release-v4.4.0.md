## 要做的

### 1. 后端 CHANGELOG v4.4.0

按下面的分类写：每项写清改了什么、对使用者有什么影响，并附 PR 链接。

- **集群与队列**
  - T101：同一实际集群的多个队列入口合并统计核数，总上限取各入口中的最小值；确认框显示入口名和 partition；不再按核时余额拦截提交，只提示本次最多消耗多少核时；新增 `allowed_templates`（例如限制 scnet-test 只能跑 CREST）；AGENTS.md 第 3.9 条补充了多入口规则。
  - T106：PBS 单作业核数上限改为可配置，不再写死 44；取消"总上限不超过单作业 4 倍"的限制；新增可选的排队上限 `max_queued_cores`；新增可选的独立 CREST 路径 `programs.crest.executable`；AGENTS.md 第 3.9 条同步修改。
- **取回与确认**
  - T102：取回改为"连续 60 秒没有进展才算超时"（另设 24 小时兜底上限），超时后不自动重试；用 `ag cancel` 取消的作业可以用 `fetch --incomplete` 取回已有输出（需满足证据条件）；确认框按钮改为"不提交 / 提交"和"保留作业 / 终止作业"。
- **新能力**
  - T105：新增 `gaussian-cp` 模板（气相 Counterpoise=2 单点，固定两个片段）和 `ag cp-report`（`ag-cp/1`）。只用于 RC、离子对、TS 相互作用能的诊断，不进入 thermo/profile。G16 A.03 不允许 CP 与 SCRF 同用，这是实测结论。

**升级须知**（单列一小节，放在本节最前面）：
1. 迁移 study 或切换配置目录时，必须把各 Slurm 入口的台账一起带上。缺台账时提交会被拒绝，这是有意的设计。
2. 新入口如果使用独立 CREST 路径，prepare 时会先通过 SSH 检查该程序是否可执行。
3. 已有配置里的 `budget_core_hours`、`expires` 不再拦截提交，可以删除。
4. default（组里集群）请在配置中明确写 `max_cores = 44`。
5. 取回超时后不会自动重试，会停下来等人检查。

**已知问题**（按实际情况写）：
- 两个不同的 PBS 集群（SSH 身份不同）会触发 doctor 的"疑似同集群入口未合并"提示。这是误报，不影响统计，后续修复。
- `cp-report --solvent-sp` 目前只接受复合物的溶剂相单点，因此溶剂相相互作用能会显示为"未知"。允许另外输入两个片段的 SMD 单点，列为后续任务。
- 取回不支持断点续传。

**写明：** 各项的真实验证结果见对应 PR 的评论；发版不等于科学验收。
