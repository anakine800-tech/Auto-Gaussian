## 分支与目标

- 分支：`codex/t83-input-checks`；基于最新 main，一张任务单一个 PR。**开发机做。**
- **开工条件：** T82 合并后（同时最多三条开发线）。
- **目标：**
  1. 准备输入时拦下三类必然无效的输入（外部审阅 10-16 复现）：坐标为非有限数（例如 `1e999`）、不存在的元素符号（例如 `Qq`）、总电子数与多重度奇偶不符；
  2. 方法表（`acceptance-methods.md`）补一节“数值设置核对”，把需要记录、核对的数值设置列全。
- **为什么：** 这些输入一定会在集群上失败，白白排队和占核；数值设置（基函数形式、积分网格、CPHF 网格）不一致，会让不同层级或不同物种的能量不可比，现在方法表只要求记一个“网格”。

## 要做的

### 1. 输入检查（准备阶段，不满足就拒绝并指明行号）

- **坐标：** 解析后必须是有限数；`1e999`、`inf`、`nan` 拒绝。
- **元素：** 元素符号必须是周期表中的元素（大小写按 Gaussian 习惯），原子序数写法须在 1–118；`Bq` 等虚原子、同位素写法本单**不支持**，遇到时明确拒绝并说明，不静默放过。
- **电子数与多重度：** 电子数 = 各原子原子序数之和 − 总电荷；电子数为偶数时多重度必须是奇数，为奇数时必须是偶数；电子数不能小于 0。不符时报错，给出电子数和多重度。（本单不判断多重度在化学上是否合理，只查奇偶。）
- 对 xTB / CREST 的 XYZ 输入做同样的元素与坐标检查（若已有等效检查，在 PR 里说明，不重复实现）。
- 已经准备好的 Attempt 不回头检查；如果提交前会重新解析几何，说明新检查对它们的影响。

### 2. 方法表新增“数值设置核对”

逐层（初筛、Opt+Freq、筛选单点、最终单点）记录并在比较前核对：

- 程序与修订版；
- 实际使用的基组（含 Gen / ECP 时的完整定义）及基函数形式（`5D`/`6D`、`7F`/`10F`，未写时注明为基组默认）；
- 积分网格；**CPHF 网格**（频率等响应计算使用，可能与能量计算的网格不同）；
- SCF 收敛标准、对称性设置（`NoSymm` 等）；
- 溶剂模型与溶剂，以及非默认的溶剂参数。

要求：

- 默认值的含义以**所用修订版的 Gaussian 手册**为准，写明出处；手册无法访问时写“未核实”，不凭记忆补写。外部审阅提到 Gaussian 官网当时无法访问，用了 CONFLEX 的 G16 手册译文；如果引用，注明是镜像或译文。
- 同一层级跨物种比较时，这些设置必须一致；不一致时写明差异及对结论的影响。
- 只新增这一节，不改方法表中已有的方法方案。
