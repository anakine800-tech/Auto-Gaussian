## 验收

1. 命令示例与实际 CLI 一致。临时副本使用 `mode-review --offline`，在研究外保留报告、正负位移与登记；正式研究使用受保护的 `--out` 路径。
2. 指定 PBS 入口可在本机只读检查历史预留与账号绑定。说明输出字段、失败退出码和仍须核实的证据，保留未回显作业的核算。
3. 后端安装元数据、导入与 CLI 版本均为 4.8.2，前端链接指向同号发布。构建并隔离安装 wheel/sdist，核对完整源码带有同提交的模板与 Skills，并核查正式安装使用的 Git 检出可提供自主计划所需的版本来源。
4. 检查相关链接、扫描器自测、全仓与暂存区公开扫描及私有词表、全量后端和 Skills 测试。由协调方核对最终提交的 CI 和独立审阅，再配对发布。

## 真实环境验证

本工单通过合成研究与假调度器做离线核对。开发机或研究机部署、生产 PBS 接单、预留解除及现场恢复按各自实际维护记录确认。既往共享节点验收保留在其原发布和日期。
