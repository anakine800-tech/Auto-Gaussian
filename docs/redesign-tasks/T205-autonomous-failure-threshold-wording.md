# T205：纠正自主暂停的三对象阈值文案

## 目标与范围

一张任务单、一个独立对话、`codex/t205-autonomous-failure-threshold-wording` 分支、一个 PR（首行 `Task: T205`）。这是已确认暂停规则的文案一致性修正，不新增约束、暂停原因或内核算法，也不启用自主运行。

将“超过三个对象”的 `>3` 纠正为：同一次唤醒内，达到三个不同对象出现同一种失败时暂停（`>=3`）。原措辞要等到第四个对象，修正后第三个不同对象出现同类失败即满足条件。重复 Attempt 或同对象多次失败不能增加对象数，不将三个对象的不同失败类型合并计数。

| 同一次唤醒内的情形 | 本条阈值的含义 |
| --- | --- |
| 三个不同对象出现同一种失败 | 达到三个时暂停。 |
| 同一对象失败三次，包括重复 Attempt | 只计一个对象，不因本条阈值暂停；其他规则仍适用。 |
| 三个不同对象分别出现不同失败 | 按失败类型分别计数，不合并成同类失败；其他规则仍适用。 |
