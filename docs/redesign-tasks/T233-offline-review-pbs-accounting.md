# T233 离线模式审阅与 PBS 本地预留诊断

## 目标

本地模式导出会登记研究写入。临时验收目录移走后，早期写入登记可能使共享账号的 PBS 预留核算失败。为纯离线验收提供独立的本地输出和登记，为历史记录提供能追到研究根的只读诊断。

## 范围

- `ag/src/ag/mode_review.py` 及必要的专用本地离线审阅模块，`ag/tests/test_mode_review.py` 或直接的离线审阅回归。
- `ag/src/ag/autonomy_submission.py`、`ag/src/ag/autonomy.py` 及必要的 PBS 本地只读诊断模块，`ag/tests/test_t233_pbs_audit.py` 或既有预留诊断测试。
- 本工单、`ag/README.md` 和 `docs/DEVELOPING.md`。保留正式研究的写锁、旧登记格式、未回显作业核算、共享账号限额和两次提交前核验。

## 验收

1. 从正式版的合成研究重现七次本地模式导出留下完整登记，原研究根移走后 PBS 核算拒绝。新的显式离线入口只读取来源研究，结果与可追溯记录在独立位置发布。原研究、生产登记和提交数据逐字节保持。正常研究的导出继续使用现有写入保护。
2. 在同一模拟生产账号保留一笔尚未回显的作业。离线研究根移走后正常核算继续计入这笔作业。旧格式登记、同级的早期作业以及缺失、替换或相互矛盾的资料继续由原有核算逐项处理。
3. 通过日常 CLI 的只读诊断，按具名 PBS 入口说明缺失的登记组、原路径、父研究根和证据缺口。完整性失败时返回非零。恢复可核原件后以完整 PBS 读取复核。目录名、完成回执、人工指定核数或单次队列快照均不足以解除预留。
4. 用隔离目录和假调度器核对正反例、源码版本、敏感信息扫描和回归。单独复核 PBS 本人作业号与可见明细冲突时提交仍被拒绝。计算电脑私有现场仅有部分历史覆盖时继续报告待核。生产配置、集群连接、真实提交与版本部署属于独立现场工作。
