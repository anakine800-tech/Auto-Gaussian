# T222 严格 Gaussian 输入的整数坐标诊断

## 分支与目标

从最新 `origin/main` 建独立工作树与 `codex/t222-strict-gaussian-cartesian-input` 分支。先读 AGENTS.md、本任务单、docs/DEVELOPING.md 和 docs/LESSONS.md。

显式分子坐标中的裸整数字段通过现行严格校验。已有非研究验证输入被 Gaussian 在读结构阶段拒绝，仅把坐标改写成实数格式就进入了优化。

## 允许改动的路径

- ag/src/ag/gaussian_input.py、ag/src/ag/attempt.py：严格 Gaussian 准备入口及与旧输入的兼容。
- ag/src/ag/autonomy_policy.py、ag/src/ag/parent_chk_report.py：仅限必要的严格重验或历史阅读兼容。
- ag/tests/：针对本问题的回归及实际依赖该语法的合成 Gaussian 夹具。
- ag/README.md、docs/LESSONS.md：面向使用者的格式提示和已发生的读入问题。
- `docs/redesign-tasks/T222-strict-gaussian-cartesian-input.md`：本单及实施、验证摘要。

## 验收标准

1. 对新准备的普通严格 Gaussian 显式几何，在原文件行指出裸整数坐标并提示实数写法，保留用户源文件及输入字节。原子序数、荷电和多重度的整数照常处理。
2. 覆盖普通分子和已有严格多结构输入；覆盖坐标中混有整数、带符号整数、合法小数和现有可用科学计数法。不扩大到 XYZ、xTB、CREST、放宽格式或任意尾段数字。
3. 对照老记录：已取回结果可阅读、核验，冻结字节及旧证据保持；明确已准备未提交输入的处理及可理解的诊断。用正常 prepare 路径覆盖错误输入在形成新 Attempt 前停止，合法输入继续。
4. 先定位共享校验调用点，再改必要的合成 Gaussian 夹具。保留整数 XYZ 与历史输入的反例。
5. 已准备但尚未提交的旧严格包，如含已知会导致 Gaussian 读入失败的裸整数，任何新派发都应在确认、远程调用及创建 claim 前拒绝，指出位置并指向新 Attempt。只提示后仍可派发会让无人值守路径继续消费核时。已带不可重提 claim 的历史包仍能只读核对、恢复回执和读取证据，保留原字节。

## 实施与离线验证（2026-11-25）

普通严格 `gaussian` 的 prepare 在解析每个分子坐标块时检查 x、y、z 的写法。错误给出第一个裸整数的轴、原值和实数示例，QST2/QST3 另给出组号。行号扣除本次自动补入的 Link0 行。解析器沿用原有有限数判定和指数语法，输入字节由原有冻结流程处理。

核对过共享读取方。xTB/CREST 的 XYZ 和合成 Gaussian 包装、放宽 Gaussian、Counterpoise 专用模板，以及 parent-chk-report、热化学单点配对、coverage 和 CP 报告均沿用兼容读取。

旧包准入在 `attempt.verified_files` 统一处理。缺少永久提交声明的普通严格 Gaussian 包按冻结文件的行号检查裸整数并指向新 Attempt，手动 `submit`（含一次性批准、长期规则、对话框）与自主 `submit` 共用此前置核验；自主方法核验也先核对同一包。已有永久声明的历史包保留原有语法用于回执恢复及只读核验，其输入哈希、摘要比对、作业绑定和不可重提规则继续生效。

- 基线使用合成临时 study 走 CLI。四组单结构和两组 QST 错误输入均意外获得 Attempt；合法实数、整数 XYZ、放宽输入和历史归档七项对照通过。
- 新增独立回归 `ag/tests/test_t222_gaussian_cartesian.py`。普通、QST2、QST3 各个组的错误输入均在分配序号前拒绝，保留源文件。完整合法输入的源文件、冻结字节和 bundle 哈希相符。覆盖 CRLF、多行标题、四种 Link0 资源组合、坐标中的正负号和 e/E、整数原子序数及 ModRedundant 的整数索引与步数。
- 用模拟传输验证普通、QST2、QST3 的未声明旧包在确认前拒绝，传输调用为零，Attempt 文件逐字节相同。绑定有效计划的合成自主入口也在调用传输前拒绝。另用旧语法构造已派发但丢失响应的历史包，用现行 status 从开始回执恢复确切作业号并核对远程模拟字节，冻结文件逐字节相同，再提交被拒绝。用 parent-chk-report 读取旧整数水分子的合成归档及频率日志，核对输入包、父子绑定和既有文件字节。定向测试还重放了仓库已有的 G16 A.03 小分子 Counterpoise 脱敏日志摘录。
- 本单 22 个独立回归全部通过，含专用 Counterpoise 模板的整数坐标与片段标签反例。全量回归发现 Multiwfn 的合成父输入直接拼入整数 XYZ；夹具在生成严格 Gaussian 输入时输出实数，原 XYZ 保留。三个共用该夹具的用例单独复验通过。既有现场读结构失败及改写后进入优化的对照来自监督工单。负责人已确认有失败与实数对照的非研究原件，将在最终 head 复核；本次仅执行本地准备、模拟传输与旧证据回放。
