# T211：测试集全局 HOME 隔离

## 目标与事故

T188 初次测试缺少 Path.home 隔离，曾尝试打开真实 HOME 的自主登记锁，权限拒绝才暴露问题。
ag 与 Skills 测试默认使用函数级临时 HOME，遗留绝对路径访问须在操作前失败。

## 范围

只改测试入口、职责单一的测试辅助文件、隔离回归、因隔离需要适配的已有测试夹具，
以及开发说明、经验和本工单。生产代码、冻结目录、真实配置/研究/SSH 文件均不修改。
不访问集群，不执行真实 study、doctor、monitor、计算、部署或定时任务；开发会话不合并。

## 验收

- 根目录、单文件、Skills 和 ag 子目录 pytest 入口自动加载；HOME、Path.home 和展开保持一致。
- 覆盖默认配置、全机锁/登记、open/目录操作、描述符相对操作、链接和实际 Python 子进程入口。
- 用临时模拟 HOME 哨兵证明拒绝先于系统调用；覆盖异常恢复吞错、环境恢复和异常退出。
- 源码按确切跟踪文件只读放行；依赖和 Git provenance 例外有限，未跟踪数据不放行。
- 写清 Python 保护范围及外部命令边界，不宣称通用 OS 沙箱；不在代理 shell 中重设 HOME。
- 只运行本地定向回归；全量交 CI，最终组合的一次本地全量由协调执行。不做 AST 比对。
- 保留首次失败及修复后证据，公开扫描后精确暂存；PR 首行 `Task: T211`，新 head CI 通过后交独立审阅。

## 实现与验证记录

入口与支持边界见 [开发手册](../DEVELOPING.md#测试范围)。首次单文件测试暴露根 conftest
未加载，后续补 ag/tests 入口；源码收集探测、另一 editable checkout 的路径和子进程
启动适配失败均保留在私有验证日志中，没有探测真实登记目录。确切提交、定向结果及 CI
链接记录在本工单 PR；离线通过不授予任何真实操作权限。
