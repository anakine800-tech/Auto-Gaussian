# T230 核对旧登记的目录来源

## 目标

设备号变化后，使用可信旧生产者的原件与系统记录核对已经登记的目录及其父根，使 PBS 能重新计算对应账号的本地预留。以 T229 为基线。

## 范围

仅限旧目录来源的本地模块、PBS 目录核对入口、直接相关测试与开发手册。原研究目录、已有机器登记、生产配置及远程系统均只读。单独授权持久安装新的索引。

## 验收

1. 验证每份实际接受的登记与旧生产者、卷、目录、用于枚举其他研究的父根之间的关系。提供原件缺失、卷不一致、父根或子目录替换的拒绝测试。
2. 保持完整的根枚举、在途预留、跨入口规则和提交前复查。相同设备的登记与有 T229 凭据的登记继续按各自规则核验。
3. 恢复信息只用于 PBS 核算。索引只能定位操作系统事件，禁止传入资源数字与目录映射，禁止给已有登记补写属性。
4. 用合成资料做离线回归。现场使用只读候选核对原件，报告逐项核算与覆盖边界。部署和真实作业单独验收。
