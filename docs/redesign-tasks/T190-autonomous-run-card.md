## 短卡必须表达

- 恢复正式计划、round、状态、实际提交计数与 pending；ended 退出，paused 仅允许有效 owner 的观察/取回/整理。finish 只结束 wake，不重置 round 预算。
- 逐动作使用当次 run/token/计划哈希，核对版本、计划/规则有效期及快照；wake 60 分钟，旧租约至 90 分钟才可接管，失权停止发布。最终参数以 T186 定稿实际帮助为准。
- status 确认作业结束后才 fetch；分别处理 facts 的 written/unchanged/skipped/conflict/failed，冲突不 refresh/reparse，UNKNOWN 不补交。取消回执不证明结束，不释放占用或触发后继。
- 科学继续判断逐条“待人确认”；TS 科学失败须正式来源证据，方法/机理变化及三个里程碑签字仍由人确认。详细补救引用现有卡片，不复制诊断阶梯。
- 路由与规则绑定；SCNet 四个活跃自主作业、兜底两个排队自主作业按本机全部 study/轮次合计，旧轮/UNKNOWN/未观测预留保留，账号核数仍包含手动作业。预算按实际提交消费，prepare 意图不另扣。
- 90% 预算、UNKNOWN、哈希不符、规则/版本失效等暂停；跨 wake 两次失败/快照过期、同 wake 三个不同对象同类失败由模型按可追溯来源计数后 pause，不宣称内核自动聚合。
- update 整体替换 summary/pending/objects，保留仍有效旧事项。study.md 及本地科学工具只经已集成的 owner 保护入口发布，不直接编辑 state/journal；缺入口时保留待办。
- 有变化才简报，一页以内，仅写完成、阻塞、需负责人决定事项；取消/改投的 Mac 点击提醒在首行，全部待确认判断保留，详细证据给私有归档链接。实际定时任务另属 T198 运维授权。

计划模板沿用已实现字段：目标、比较组、方法、主/小体系、耗时预估、Attempt 上限、到期及 submission_policy；版本由工具采集。试点关闭范围、逐类耗时等放入已有文本，不发明开关字段，不把文字当作内核关闭的证据。
