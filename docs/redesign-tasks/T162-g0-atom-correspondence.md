# T162：G0 显式原子对应与模式来源绑定

版本：v1，2026-10-28。目标仓库：Auto-Gaussian。类型：本地实现单。覆盖 H2。

## 分支与目标

- 分支：codex/t162-g0-atom-correspondence；一个任务单、一个分支、一个 PR；PR 第一行：Task: T162。
- 基线：开工时最新 main，且 T161 已合并。已核查基线为 e24a5bd1d9045e3b783d8ef25f02e430ad4dc3c5；先读 AGENTS.md → 本单，再读 docs/DEVELOPING.md、docs/LESSONS.md 和历史依据 T137/T138。
- 目标：把“元素序列相同”和“已声明且绑定来源的原子对应关系”分开；按可靠对应关系将候选反应坐标映射到频率几何编号，避免同种元素换序后仍产生貌似可靠的方向判断。
- 事故依据：g0._integrity 只比较 frame.symbols，g0_modes.analyze_candidate 也只比较元素序列；同元素置换不会改变序列，反应原子编号却可能对应错误。
- 本单不做自动原子匹配、不引入提交门禁。程序只验证映射的完整性、元素一致性及来源绑定；映射的化学身份仍由提出映射的人审阅。
- 并行：资料核查可提前；修改 g0.py、g0_modes.py 和对应测试须在 T161 合并后进行。T163 的资料调研可并行，最终导入规格引用本单完成的编号规则。

## 要做的

1. 保留原子数、组成、电荷/多重度和损坏几何检查；新增清楚独立的“身份对应”说明。元素序列相同只表示序列检查通过，不得再表述为同元素原子的身份已验证。
2. 在现有 ag g0 中新增可选 --atom-mapping 参数，读取一个本地 JSON 文件。文件可为单候选或批次提供条目；每条按 object、candidate 和确切目标来源定位，不按列表位置隐式配对。
3. 每个对应关系必须包含：
   - 候选存档 XYZ 的 SHA-256；
   - 目标类型（参考输入几何或频率模式几何）、确切 Attempt、所用源文件哈希；几何来自 JSON/日志时保留 JSON Pointer 或频率段范围/段哈希；
   - 从候选 1-based 原子号到目标 1-based 原子号的完整双射，方向必须在文档和输出中明确；
   映射输入不保存自己的哈希。程序读取映射文件原始字节后计算 SHA-256，仅写入本次诊断的来源记录。内部字段名由开发者统一在 docs/g0.md 给出，不创建额外“schema 合同”文档。
4. 格式校验须拒绝遗漏、重复、越界、非整数、原子数不符、元素不一致、目标不唯一和哈希不符。一个候选到参考输入的映射不能自动当作它到频率几何的映射；两种目标需要各自绑定，或在报告中展示实际可核验的组合来源。
5. 不通过 RMSD 最小值、元素同名、图对称性、origin=scan/qst 或 parent Attempt 标签自动证明对应。先审查当前导出路径是否保存了足以证明保序的来源；没有就明确未核实。只有同一已核验来源、无编号变换的直接同源关系才能作为自动保序证据，并在测试中证明，不靠 origin 字符串推断。
6. 无可用对应证据的旧候选照常读取、显示几何与组成诊断，但将身份对应记为未核实；依赖候选原子身份的模式方向结论保持 unavailable，说明缺何种映射。不得把未核实升级为 scientific rejected，也不得修改 prepare/submit。
7. 有有效声明时，只转换反应坐标原子索引或同步进行等价的索引视图；不能旋转频率位移向量后继续使用原几何。所有模式仍使用 read_modes 返回的同一取向。输出同时显示候选编号与频率编号，沿用 T138 的符号、单位和排序约定。
8. 区分“声明映射的格式和绑定已校验”与“化学对应已由工具证明”。重复元素的合法双射仍可能由人填错，报告必须保留这项限制。
9. 旧 catalog 事件、候选文件、manifest、facts、既有诊断均不改。--record 仅显式追加本次新诊断，沿用 T161 的记录与退出码规则；不改 assignment，不添加新的科学签字。
10. 在 T161 仅将频率段歧义作为可恢复错误的基础上，本单显式新增“单候选映射格式/完整双射无效”和“映射声明的目标身份或绑定不匹配”两类可恢复错误：记录该候选的错误，不输出其模式结论，保留其它候选结果。不得用宽泛 except 捕获所有 ValueError。映射声明中的预期哈希与完好来源不符属于该条映射失配；候选存档、日志或 catalog 自身的哈希/完整性校验失败、路径越界和符号链接等，仍按 T161 整批停止且不追加 --record。测试分别覆盖这两种情形。

## 测试

| 场景 | 预期 |
| --- | --- |
| 两个同种元素交换行，元素序列不变，无映射 | 序列检查一致；身份未核实；不输出已可靠映射的反应方向 |
| 合成完整显式双射，反应坐标涉及被置换原子 | 目标编号正确；投影等于人工构造的同编号对照 |
| 映射遗漏、重复、越界、元素不符 | 明确错误，不猜补 |
| 候选/参考/频率段任一哈希变化 | 拒绝使用对应关系，报告具体绑定失败 |
| 参考映射存在，频率映射缺失 | 不把前者自动沿用到频率几何 |
| 同源保序路径（若启用）及被改动的反例 | 只有来源关系实际可核验时接受 |
| 模式整体取向与对应索引 | 位移与几何保持同取向，不引入反射/自动旋转 |
| 旧 catalog、批量局部错误、显式 --record | 旧字节不变；成功与失败来源保留；无自动 assignment |
