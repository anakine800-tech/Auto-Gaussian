# T68：RDKit 推断风险验证（只测试、只报告，不改代码）

## 分支与目标

- 分支：`codex/t68-rdkit-inference-validation`；基于最新 main（`36e6c1f` 或之后），一张任务单一个 PR。**开发机做。**
- **目标：** 用合成小模型检验 `ag topology`、`ag irc-compare`（以及它们共用的 `geometry.infer_molecule`、`graph_key`、`stereo_key`）在含硼、带电荷和两性离子体系上，键、形式电荷和立体判断是否正确。**这一轮只写测试和报告，发现问题不修**，修复另开工单。
- **为什么：** HSS 的 M1 试点（028）在 GFN2 下发生 C4–C15 成键（两性离子塌缩成环丁烷），诊断依赖 `topology`；BCB 课题有四配位硼加合物、nitronate 和两性离子中间体。这些工具靠 RDKit 从坐标推断键级和电荷，在这类体系上可能推断失败，甚至给出错误的立体判断。判断错了，科学结论就会错。

## 要做的

1. **构造合成模型（每种至少一对：变化前 / 变化后，或两个立体异构体）：**
   1. N–Bpin 二氢吡啶片段（中性，三配位硼）：例如 N–Bpin-1,4-二氢吡啶的最小模型；
   2. 四配位硼加合物 B⁻←O⁺：例如 BF₃·丙酮、B(C₆F₅)₃ 的简化模型（BF₃ 或 BH₃）·乙酸甲酯羰基、·硝基甲烷氧；
   3. nitronate（硝基 α-碳负离子）及其质子化形式；
   4. 烯醇负离子（局域 O⁻）与相应酮；
   5. 两性离子：亚胺鎓（N⁺=C）加局域 O⁻ 的最小开链模型，和它闭环得到的环丁烷（C–C 成键）——对应 028 的情况，用通用小分子构造，不用 HSS 的结构；
   6. 一对仅立体不同的分子（含一个四配位硼或一个与硼相邻的手性中心）。
2. **对每个模型检查：**
   - `infer_molecule` 能否成功；推断出的键、形式电荷、总电荷是否和预期一致；
   - `ag topology`（minimum 模式）对“变化前 / 变化后”是否正确报告 `changed` / `unchanged`，以及原因是否正确（成键、质子位置、片段数）；
   - `stereo_key` 能否区分立体异构体，能否在“仅坐标微扰”时保持不变；
   - `ag irc-compare` 对一个合成的“端点 vs 参考”组合，连接、电荷、立体判断是否正确；
   - 推断失败时，工具是明确报错 / 报 unknown，还是**静默给出错误结果**（这是最危险的情况，要重点标出）。
3. **报告（`docs/research/rdkit-inference-risk.md`）：** 一张表，行是模型，列是：推断是否成功、键是否正确、电荷是否正确、拓扑判断是否正确、立体判断是否正确、失败方式（明确报错 / unknown / 静默错误）。最后写结论：哪些体系可以信任现有工具、哪些需要人工核对、建议的修复方向（每条写清影响哪个命令）。
4. **另写一段给 HSS 主会话的只读核查说明**（放在报告末尾，不含研究数据）：说明在计算机上如何用同样的检查方法（`ag topology` 及测试中用到的函数）只读检查 028 的种子和优化末帧，结果只写进 study。
