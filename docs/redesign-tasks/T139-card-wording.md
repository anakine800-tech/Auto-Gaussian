## 要做的

### A. 九条口径

1. **共同参考态**（profile.md 的选择性与曲线部分；kinetics.md“选择性”一节）
   - 写明不同前体的局部能垒不得直接相加或比较，并给出算例：前体 A 自由能 0、局部垒 10；前体 B 自由能 3、局部垒 9 → 共同参考下分别是 10 和 12，不是 10 和 9。
   - 系综加权或比较前须核对：共同参考态、标准态、热修正设置、计量与浓度项、前体之间的互变是否足够快（有独立依据）。
   - 说明 profile 输出里的 `highest_local_barrier_TS` 和 `step_decomposition` 是**各步局部能垒**，不能跨前体当作产物通量比较。
   - **固定句**：“局部能垒只在同一前体内有意义；跨前体比较必须回到共同参考态。”
2. **三数报告**（profile.md、kinetics.md）
   - 选择性同时报告 profile 的 `lowest_ts`（每个产物分支取单个最低 TS，保留 paths，不对构象求和）、系综 ΔΔG‡ 和两者之差；说明它与 `lowest_conformer` 的区别。
   - **固定句**：“单结构结果和系综结果不是同一个物理量；差值大说明结论对构象采样敏感，不代表哪个更正确。”
   - 方法学参考引用 Laplaza 2024（X2），写成“来源：”行。
3. **简并因子**（profile.md、kinetics.md）
   - 系综中只能使用真实的对称简并（构象简并度 d、等价路径数 paths、转动对称数 σ 分列，σ 不得再乘进前两者），并写明来源。
   - DFT 层要先去重（多个低层构象常收敛到同一个 DFT TS），再进入系综。`cluster --mirror` 给出的计数依赖去重输入和映射判据，不能直接当作真实简并导入 TS 统计（审计第 2 节）。
   - **固定句**：“重复找到同一个 TS 的次数不是简并度。”
4. **覆盖状态词表**（ts.md 的覆盖与失败记录部分；profile.md、kinetics.md 涉及覆盖结论处）
   - 凡是表示“采样已经够了”的说法，统一改为：**固定句**“在声明的通道范围与采样预算内稳定”。
   - 列出通道六种状态及含义（与 `docs/ag-catalog-2.md` 一致）：未尝试 / 已尝试未找到 / 暂定找到（待负责人确认）/ 已验证 / 待确认通道（采样中新发现）/ 低置信度排除；说明哪些由候选事件派生、哪些必须由负责人声明并附原话。
   - 写明 catalog 的“候选 / 采用 / 退役”是对象采用状态，不是通道覆盖状态，两者不要混用。
5. **IRC 政策**（irc.md；ts.md 结果判据部分）
   - 哪些 TS 必须做 IRC，改为按**各产物分支内部**的重要性和结构新颖性判断，不按全局权重。必做情形逐条写出：引入新的成断键集合或质子转移方式；引入新的活化模式；在所属分支内贡献显著；改变最低 TS 排名或明显改变预测的 ee / dr；模式或产物归属存在歧义。
   - 说明理由：高选择性反应中次要产物的全部 TS 全局权重都可能很小，但它们决定 er 的分母。
   - 被暂缓 IRC 的候选仍然是“未验证”，不能称为已验证（X3）。IRC 两端必须继续优化并确认为极小点，不得把有限步数的路径终点直接当作稳定物种。
6. **删除“通道泄漏 → 快速互变”的推断**（kinetics.md 的选择性与可逆性部分；crest-screen.md 的约束构象搜索部分）
   - **固定句**：“约束、带偏置的低层采样中出现通道泄漏，不证明真实体系中两条通道快速互变，不能用来支持 Curtin–Hammett 条件。”
   - Curtin–Hammett 条件需要独立的动力学依据（已有要求保留）。
7. **刚性变换全部冲突**（ts.md 失败与处理部分）
   - **固定句**：“一组模板和变换全部冲突，只说明这组模板和变换失败，不构成排除该通道的依据。”在台账中登记失败类型，不设通道排除。
8. **低层端点塌缩**（ts.md 失败与处理部分）
   - **固定句**：“低层优化塌缩到端点，只说明这条低层路线失败；通道应改用其他方法继续，不能据此排除。”
   - 登记方式：`candidate-result --outcome minimum`，note 写“低层路线失败（<方法>）”；不声明 excluded。
   - xTB 无虚频、虚频方向不对，同样只降优先级或转为直接做 DFT（与 T138 的标记一致），不排除候选。
9. **TS 后分岔**（ts.md；profile.md、kinetics.md 的选择性部分）
   - 产物分支不能唯一确定时，候选结果的归属用 `undetermined` 并列出候选通道；这样的 TS **不放进** profile 的简单选择性定义（profile 要求每个 TS 唯一归属）；在报告中标注“简单 TS 能垒比不适用”。
   - 本期不做轨迹计算；单条 IRC 也不能排除另一分支（已有表述保留）。

### B. ts.md 新增“TS 初猜工作流”一节

按顺序写成可以照做的步骤，每一步给出命令骨架（全部用占位符）和边界说明，命令名和参数以合并后的代码为准：

1. **定义对象与通道**：`ag catalog object`（期望组成、电荷；`object-suggest` 只给建议）、`ag catalog channel`（化学定义由人写；采样中新发现的用 `--discovered`）。
2. **产生候选**：
   - 扫描：先 `ag scan-path` 看沿程诊断，再 `ag scan-peak --gaussian-ts --route`；峰附近有警告时先人工审阅；
   - 两端点：`ag qst-endpoints`（完整映射文件、对称歧义报错、只做正规旋转）；
   - 手工、文献来源：`ag catalog candidate`（文献来源必须带 DOI）。
   - 草稿不含 Link0：prepare 前须按档位补 `%nprocshared`（`%mem` 可由 prepare 补齐）。
3. **登记候选**：`--register-candidate` 或 `ag catalog candidate`；登记只是来源记录，不是科学判断。
4. **G0 诊断**：`ag g0`（只有输入完整性和几何损坏两类硬拒绝；其余是标记；顺序只是建议）；有频率结果时用 `--modes-attempt` 做模式投影（断键伸长、成键缩短；不设阈值）。**固定句**：“G0 是本地诊断，不是门禁；提交与否由负责人决定。”
5. **提交**：照常 prepare / submit，提交审批规则不变（AGENTS.md 3.4）。
6. **登记结果**：`ag catalog candidate-result`（outcome、归属；暂定归属不需要原话，已验证归属需要原话并满足 X3）。
7. **通道声明与覆盖结论**：`ag catalog channel-status`（verified / excluded-low-confidence / cleared，需原话）、`ag catalog coverage`（需原话，写明通道范围和采样预算）；用 `ag catalog ledger` 作为“已尝试未找到”的依据。
8. **X4 提醒**：v4.6.0 在两台电脑部署完成之前，真实研究 study 不写 v2 事件（第 1、3、4 步中的 `--record`、第 6、7 步）。
