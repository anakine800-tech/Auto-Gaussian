1. [Raw scheduler audit](../../scheduler-raw-evidence.md) persists exact acquired
   stdout/stderr and closed request/job binding before normalization, reopens
   durably, retains evidence after parser failure, and prevents normalization
   if persistence fails. Tampered payload/index columns, cross-binding and
   non-authoritative audit-row reuse reject; existing store/normalized behavior
   stays compatible. Claims exclude wire failures before a closed result.
2. [Level-2 packet preparation](../../level2-requalification-packet.md) deterministically
   binds the supplied exact source, input, ownership, resources, adapter and

   are missing. Missing facts produce explicit blocked partial preparation.
   Candidates contain no approved decision, live snapshot, production
   attestation, persisted Core record or current effect authority. Pure
   source-owned renderers determine the previews.
3. [Local program inventory](../../program-qualification-tooling.md) rejects unsafe,
   unavailable or drifting paths and incomplete xTB runtime-data inventories.
   Bounded reads and end-of-read identity/inventory checks preserve the local
   no-follow contract. No process starts. Captured version claims close to
   the exact supplied binary while remaining explicitly unverified, and CREST
   claims other than 3.0.2 reject. Inventory success never means production
   qualification or permission to install/run.
4. Focused synthetic adversarial checks cover the new boundaries, with bounded
   adjacent compatibility where needed. No safety test is deleted to reduce
   affected runtime, no modern unknown path gains implicit full authority,
   and no live effect is invoked by an offline check. Prefer bounded checks;
   a remaining required full/full-CI gate must be reported explicitly rather
   than bypassed or represented as already passed.
5. Status distinguishes integrated product capability from unverified current
   production facts, incomplete scientific qualification and separate live
   authority. It does not infer that programs are absent from a server merely
   because this offline review has not observed them. Historical incomplete
   Level-2 evidence remains unchanged and fresh scientific qualification is
   still required.
6. The assembled collection contains and verifies every cross-lane document,
   context reference and selected test owner. A lane-only worktree cannot
   claim missing sibling dependencies passed. Exact diff/tree evidence and
   independent findings-first review precede serial local integration; main
   submission remains pending the Owner's final decision.
