# Auto-G16 direct Study xTB execution contract

FROZEN on 2026-10-13 after independent parent review of the agent-authored draft and native owner call sites. This is engineering implementation authority within the existing four-part Owner continuation; it is not installation qualification, a live gate or permission to calculate. One implementation unit closes a public xTB path; it does not claim CREST/Gaussian/thermochemistry completion. Existing /1 and /2 immutable creation schemas, request science/resources, native /1 wire evidence and old fixed Controller paths are unchanged. This document supersedes direct-study-runtime §§2,3,5–8 and the xTB portions of direct-study-stage-session/direct-study-execution drafts only where this vertical defines the behavior. It does not revive their proposed installation_id, accept a naked preconstructed snapshot, or allow caller callbacks. Their other stages remain DRAFT; frozen runtime §1/1A/4 and later local owner contracts remain effective.

## 1. Reused vocabulary and product boundary

Reuse direct-study-fresh.md for request/identity generation, direct-study-registration.md for registration/four-owner scope, direct-study-local-install.md for mechanical installed facts, and native Publisher/collection schemas for their nested objects. Do not create a parallel approval or qualification model. `F` below is the existing closed file binding `{path,parent_chain,file_identity,sha256,size_bytes}`; `D` is existing `{path,parent_chain,file_identity}` directory binding. Native physical-node encodings retain their owner encoding, with explicit typed conversion when Study pairs become native `{device,inode}` objects.

All new Study documents use canonical encode bytes, duplicate-key rejection, no floats outside existing scientific schemas, positive nonbool counts, lowercase 64-hex SHA256, canonical UUIDs, UTF8, and cap 2 MiB (snapshot 8 MiB, input 16 MiB, raw probe evidence 16 MiB under existing native caps). Free text reviewer IDs are nonempty <=256 codepoints; no control characters. Windows are exact `{starts_at,expires_at}` canonical UTC timestamp strings; start < expiry, checked before each authorized effect. Native schemas that use different field names keep their own names, not silent relabeling.

The existing command family remains `python -m auto_g16.study` from actual installed archive. Existing create, install-local and directory-based /1 operations stay compatible. New stage actions require `--stage xtb` and /2; any other stage rejects before effect. New commands accept `--directory` only to resolve the already installed/registered Study; neither paths nor caller data select installed roots, remote root, profile or handlers.

Commands:
- `run --directory D --initialize-local`: current local initialization, then registration in a separate lock scope. Partial registration never repaired automatically.
- `review --directory D --stage xtb`: local preview/readiness or exact prepared review; no remote call or publication.
- `authorize-preparation --directory D --stage xtb --request FILE --sha256 SHA`: import the exact preparation decision below, zero remote.
- `run --directory D --stage xtb --action prepare`: one authorized native preparation operation.
- `authorize --directory D --stage xtb --request FILE --sha256 SHA`: import exact three decisions and native evidence references; zero remote.
- `run --directory D --stage xtb --action submit`: current session → existing Controller → execute_once only.
- `review-collection --directory D --stage xtb --request FILE --sha256 SHA`: build the exact local native continuation scope from current original receipts, four handles and installed collector source; FILE is only `{schema,window}` with schema auto-g16-study-xtb-collection-window/1. Zero remote.
- `authorize-collection --directory D --stage xtb --request FILE --sha256 SHA`: import one explicit decision against that preview digest and its original evidence, generate native continuation/reviewed scope; zero remote.
- `run --directory D --stage xtb --action collect --continuation-sha256 SHA`: consume only that approved native epoch; one invocation, no polling daemon/auto-restart.
- `status/query/audit/recover --directory D --stage xtb`: read-only local native validation. Default recover performs no repair, remote observation, submit or approval.

No arbitrary action, module, callback, driver, remote path flag, source root override or `_FIXED_*` assignment. The parameter-free installed loader remains the only deployment locator. Public unflagged run still rejects. Parser rejects incompatible flags before opening stores.
