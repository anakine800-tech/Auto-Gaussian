# T191：同骨架 TS 迁移基准（离线方案，未执行）

本单交付固定样本的方案和专用初猜原型。生成 XYZ、登记候选、prepare 或测试通过都不是 TS 科学通过；当前科学成功数为 **未测定 / 4**。无真实 study、Attempt、集群查询或量化计算。通用 CLI、自动识别成断键和目录集成留待基准通过后评估。

## 先固定问题和分母

拟以同一环丁烯开环模板向四个同骨架取代物迁移；来源、逐原子表和目标通道在下文固定。每个目标只取一个预先选定的反应物立体异构体、一个开环通道和一个代表构象，不声称构象覆盖或立体选择性预测。四个目标是相关样本，不能外推为四类反应。

首轮分母固定为四，包括无法嵌入、优化失败、错误鞍点、IRC 不完整、端点不符或来源证据不足的项。不得根据结果替换分子、通道或删除失败项。严格超过一半意味着至少 **3/4** 合格。首轮成绩和修正后成绩分开呈现；最多一轮修正，逐目标记录原失败、单个改动、理由和全部新增成本。修正仍不足 3/4 时建议从本版摘除；预算或证据不足则记未完成，不能宣称通过。

每次成功必须同时有：同一最终方法的优化与 Freq 正常完成并符合现有收敛判据；恰好一个虚频且人工审核方向对应环开裂/键级重排；从同一 TS 分别完成 forward/reverse IRC；两端分别完成无约束 Opt+Freq、零虚频和按原子映射的身份/立体核对。产品 E/Z、反应物相对构型、质子化和 COOH 身份都不能只靠 RMSD。IRC 点数耗尽不是完成，暂时鞍点不是成功。复用模板同样必须满足这些判据；文献的一个虚频声明不替代双向 IRC。

## 完整成本与待负责人决定的取舍

计数单位是每个新 Attempt；Opt+Freq 可在同一个 Gaussian 作业内计一次，两个方向 IRC 分开计数，两端 Opt+Freq 各计一次。扫描作业即使包含多点也只计一个 Attempt，因此必须同时报告扫描点数、优化步数、Hessian 次数、申请核数×时限及实际核时。失败、早停、补救、模板和对照均进入总账，不通过合并计数掩盖计算量。

原定目标约 30、硬上限 60、达到 **54（90%）即暂停**。54 不是额外 6 次自动额度；到阈值不创建新对象或补救。以下是交协调方请负责人选择的具体选项，**都不是本单执行授权**：

2. 先做预先指定的前两对探索：5 + 2×12 = **29**，含一次模板获取预留为30；一轮两个迁移修正另12（共41，含获取预留42）。这是分母 2 的试点，不能作为四对基准发布通过；其余两对仍待完成且结果保留。
3. 本版仅交付方案及离线原型，延后真实四对基准和通用工具。这也是可选方案，尚未由负责人决定；本单仅获准离线开发，真实执行安排仍待协调方提交科学/预算决策。
