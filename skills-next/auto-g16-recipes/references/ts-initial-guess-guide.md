## 从候选来源选择入口

| 已有材料 | 工具作用 | 仍需人审阅 |
| --- | --- | --- |
| 一维弛豫扫描 | `ag scan-path` 沿程诊断，再用 `ag scan-peak` 选择合格内部局部峰并导出草稿 | 坐标、范围、收敛、构象/电子态连续性；峰只是初猜 |
| Gaussian 二维弛豫扫描 | `ag scan-peak` 显式选择已列出的网格候选 | 两条扫描坐标及候选位置；`scan-path` 不支持二维 |
| 两个优化端点 | `ag qst-endpoints` 根据完整人工映射对齐并生成 QST2 正文 | 端点身份与极小点证据、原子对应、对称歧义、实际输入行序 |
| 手工或文献几何 | 人审后按需用 `ag catalog candidate` 留来源 | 文献 DOI/SI 位置与结构内容、方法适用性、映射和未覆盖部分 |

QST 只做正规旋转和平移，不镜像、不推断映射；`--keep-mapping` 必须说明理由，不能代替审阅。自动登记的几何是对齐后的产物端点，不是已找到的 TS；新取向不能直接读取旧 chk 的 Cartesian 力常数。

以下均为待替换的占位示例，方法与 route 由已审阅方案提供；文件用新名字。命令只生成本地草稿，不自动 prepare 或提交：

```sh
ag scan-path <扫描Attempt> --study <study> --expect-bond <I-J> --json
ag scan-peak <扫描Attempt> --study <study> --out <新XYZ> --gaussian-ts <新GJF> --route '# <方法/基组> Opt=(TS,CalcFC) Freq' --expect-bond <I-J> --json
ag qst-endpoints <study> --reactant <反应物Attempt> --product <产物Attempt> --mapping <完整映射JSON> --route '# <方法/基组> Opt=(QST2,CalcFC) Freq' --out <新QST2_GJF> --json
```

生成草稿不包含 Link0。prepare 可按明确档位补缺失的 `%nprocshared` 和 `%mem`；T154 允许所选入口已配置 `resources.default_tier` 时省略 `--tier`，显式档位优先，没有默认值时仍须选择档位。walltime 仍须明确，补齐不决定方法、不授权提交，也不重写旧 Attempt。

## 登记、G0 与结果归属

对象声明期望组成、电荷和多重度；通道由人给化学定义；候选保留几何哈希、来源和目标通道；候选结果记录实际尝试与归属。显式登记会追加 catalog 事件，默认草稿生成和 G0 诊断不会自动登记。生成命令的 `--dry-run` 仅预览登记，仍会写草稿；失败后先核对已写文件，不能自动重跑。

catalog v2 不可降级；已有 v1 日志首次写 v2 事件须显式 `--upgrade-catalog`，其格式确认不替代研究写入授权。状态优先级、`--discovered`、确认和撤销见 [catalog v2](../../../docs/ag-catalog-2.md#5-通道派生与查询)；不要凭简化状态表跳过实际结果台账。

```sh
ag catalog ledger <study> --object <对象> --channel <通道> --json
ag g0 <study> --object <对象> --candidate <候选> --windows analyses/<窗口JSON> --json
ag g0 <study> --object <对象> --candidate <候选> --windows analyses/<窗口JSON> --modes-attempt <频率Attempt> --reaction-coordinate distance:<I-J>:forming --atom-mapping <映射JSON> --json
ag g0 <study> --object <对象> --all --windows analyses/<窗口JSON> --json
```

窗口、反应坐标及原子对应由人审阅，不能直接把原稿示例编号用于研究。T162 用 `--atom-mapping` 声明显式对应：顶层 `mappings`，完整且从 1 开始的 `candidate_to_target` 表示候选 → 目标；reference/frequency 分别绑定候选与实际来源的 SHA-256，频率还绑定确切日志段。详见 [显式原子对应](../../../docs/g0.md#显式原子对应t162)。`declared_verified` 只证明声明校验通过，不证明同元素化学身份。

缺映射时身份保持 `unverified`，不增加科学拒绝或提交门槛；没有有效 frequency 映射就不提供模式投影。模式使用已取回 Gaussian 频率的原几何与原位移，只转换候选反应坐标的索引，不旋转/重排模式；逐内坐标报告变化并考虑整体正负号。重叠度只供排序，不设科学通过阈值。xTB Hessian 尚未接入；[T163 调查规格](../../../docs/research/xtb-hessian-import.md)保留真实配套文件与数值边界缺口，不能将 `g98.out` 交给现有 Gaussian 适配器。

候选诊断只把输入完整性与极端几何损坏归为 rejected；普通冲突、超窗、立体和模式问题为标记。数据、来源或解析错误是操作错误，不能归入 clean/flagged/rejected 来掩盖。完整限制与阈值以 [G0 文档](../../../docs/g0.md)为准。

T161/T162 批量诊断对明确分类的频率分段歧义、可定位到候选的映射声明或绑定错误保留成功项，并单列错误，退出码为 2；出现局部错误时 `--record` 不写任何候选事件。单候选仍直接报错；映射文件读取/顶层身份错误、来源本身损坏、非法路径等仍停止整批。成功项的顺序只是建议，G0 不构成提交门禁。

完成获批计算后，按实际结果登记。accepted 本身不等于 verified；verified 归属的机器条件不证明振动方向或 IRC 已验收；通道 verified 另需负责人声明。归属不唯一时记录 undetermined，不把同一 TS 重复计入不同产物的简单选择性。

## 科学审阅与后续分析

- TS 优化和完整 Freq 通过后，必须按原始负频计数恰好一个虚频，并由人审核目标成断键的协调方向；G0 排名、程序正常结束或一个负频都不能代替该审阅。
- 双向 IRC 必须分别满足 [IRC 卡片第 6 节](../cards/irc.md#6-结果判据清单)，两侧末点分别独立 Opt+Freq 为极小点，并识别端点后才能声称验证。按各产物分支内部的重要性安排，暂缓仍是未验证。
- 一个模板组失败、低层路线塌缩或没有合格局部峰，只说明此次搜索的结果，不能排除整个通道。保留失败类型、来源与预算，覆盖结论限于“在声明的通道范围与采样预算内稳定”。
- profile 使用共同参考态；重复搜索次数不当作简并度，构象简并度、反应路径数与旋转对称数分别审阅。约束/偏置采样中的通道转换不能代替 Curtin–Hammett 的独立动力学依据。
- profile 的 `lowest_ts` 每个产物分支取修正后自由能最低的单个结构，保留真实 paths，不做构象求和或乘构象简并度；系综使用构象汇总，差值为系综减最低 TS。两者物理量不同，差值大不证明哪个更正确；原 `lowest_conformer` 语义不变。
