# 反应机理计划

## 1. 适用范围

主族闭壳层同一势能面的反应机理研究规划。用“假设 → 计算 → 修正”组织工作，防止先选定机理、再只保留支持它的结果。规划可以列出多个物种和步骤，但不据此开放双分子初筛、金属、开壳层或激发态计算。

借鉴 [ARCHE，arXiv:2609.11147v1](https://arxiv.org/abs/2609.11147v1) 的 Results / “ARCHE System Architecture”（pp. 5–6）与 Methods / “Reasoning–validation circle”（pp. 18–19）：提出竞争假设，用有区分力的计算检验，按矛盾证据修正。下面的 study 记录、可推翻条件及人工签字是本项目的落实方式，不移植论文的自主执行模式。

## 2. 前置条件

已明确科学问题、实验约束和方法依据；区分直接文献先例与类比。读取 [study 模板](../../auto-g16-study/references/study-md-template.md)，记录各物种的身份、原子对应、电荷、多重度和立体化学。未知项写待确认，不猜填；机理假设未签字时只做规划，不推进依赖该假设的计算。

## 3. 输入模板

在仓库外的 `study.md` 填写以下内容，不另建合同或 schema：

```text
机理假设 H1（日期；待人签字）
问题与实验约束：<反应、条件、观察与文献位置>
竞争假设：<H2 的差别；若暂无线索，写尚未检索充分>
步骤：<R → TS1 → I → TS2 → P；逐步写成键/断键原子对>
待算对象：<每个 R/I/P 的构象；每个 TS 的初猜和构象；双向 IRC 与端点极小点>
判别计算：<本轮最能区分 H1/H2 的结构、能垒或其他量；方法和依据>
推翻条件：<如合格双向 IRC 连到其他物种，或统一模型下的能垒与实验时间尺度不相容；写依据和不确定性>
未决问题：<缺结构、方法先例、程序能力等>
签字：<日期、签字人、明确确认原意；未确认保持待签>
里程碑后更新：<里程碑、证据位置、支持/反对/不足、保留/修正/放弃、下一步、签字适用对象>
```

流程：先写假设及其可推翻条件，请人签字；按 [Opt+Freq](opt-freq.md)、[TS](ts.md)、[IRC](irc.md) 卡片提出计算；审阅结果；在结构、代表构象集合、最终结果每个里程碑之后更新假设。TS 振动审核和 IRC 端点识别产生新证据时也及时更新。未改变的假设写“保留及理由”，改变步骤、物种、TS 或推翻条件时写修订并重新请人签字，旧签字不套用到新假设。

## 4. 资源建议

本卡只做本地规划，不占集群资源。先列最小判别计算，按对应卡片估计每个 Attempt 的档位和 walltime；柔性体系要将多个 TS 构象的代价列入，不把所有候选一次性提交。科学假设签字不授权提交。

## 5. 提交前检查清单

- 本卡不提交；假设包含逐步机理、全部所需物种和 TS、可推翻条件及人的签字。
- 原子、电荷守恒与原子对应明确；跨自旋面、碎片电荷不明等超范围问题已记录并停止相关步骤。
- 新计算前展示结构、电荷与多重度、立体化学警告、方法依据、完整 route、档位、walltime、远程目录和输入哈希；提交仍需人点击 Mac 对话框。
- QST2/QST3 多结构、跨 Attempt 复用 chk、扫描额外输入段、自动 TS 初猜和 IRC 端点自动比对均待 T13；缺哪项就暂停依赖它的步骤，不制造新命令。

## 6. 结果判据清单

- `study.md` 中每个机理步骤能对应到待算对象、已获事实和 review；没有计算的对象不写成已验证。
- 每个里程碑后都有假设更新记录；反证和失败保留，区分“数值计算失败”“证据不足”和“合格证据反对假设”。一次 TS 搜索失败不能推翻整条机理。
- 修订后的假设经人重新签字，之后才推进依赖它的工作；未变化的确认对象可沿用既有签字并注明。
- TS 恰好一个虚频且方向正确仍只是候选；IRC 必须两个方向都走完并识别端点后才能声称验证。仅一条可行路径不能证明唯一机理。

## 7. 常见失败与处理

证据与假设冲突时，先查数值收敛、结构和比较方法是否一致；有效反证则修正或放弃原假设，列出替代假设、最小判别计算并重新请人签字。需要补算时提出新 Attempt，等人确认。

能力缺失时在 study“当前阻塞”写对应的结构、提交、解析、科学审阅或环境原因及“待 T13”；已知结果仍可整理，但不绕过缺口。真实环境意外先停止报告，按 [异常说明](../../auto-g16-study/references/unknown-and-failures.md)处理。

## 8. 常见坑

- 把方法失败当作机理反证，或忽略与实验不相容的结果，都会误导下一步；记录证据有效性，再改假设。来源：ARCHE Methods / “Reasoning–validation circle”，pp. 18–19。
- 人签机理假设表示同意检验该假设，不等于认可结论，也不替代结构、代表构象集合、最终结果三个签字。
- `ag graph --study <study_dir>` 只展示 Attempt 的父子来源关系；它不证明化学连接关系，也不表示机理因果关系。IRC 端点连接关系自动比对待 T13。
