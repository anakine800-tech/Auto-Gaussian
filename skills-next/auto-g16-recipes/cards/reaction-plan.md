# 反应机理计划

## 要点

- 用于主族闭壳层同一势能面的机理规划，以“假设 → 计算 → 修正”组织；不据此开放金属、开壳层或激发态计算。（[见第 1 节](#1-适用范围)）
- 计算方案与机理假设一起签字；方案改变须保留旧记录并重签，签字前不准备依赖该方案的 Gaussian Attempt。（[见第 3 节](#3-输入模板)）
- 本卡只做本地规划，先列最小判别计算及各 Attempt 成本；科学假设签字不授权提交。（[见第 4 节](#4-资源建议)）
- 一个虚频且方向正确仍只是 TS 候选；双向 IRC 完成并识别端点后才能声称验证，一条可行路径不能证明唯一机理。（[见第 6 节](#6-结果判据清单)）

## 1. 适用范围

主族闭壳层同一势能面的反应机理研究规划。用“假设 → 计算 → 修正”组织工作，防止先选定机理、再只保留支持它的结果。规划可以列出多个物种和步骤，但不据此开放金属、开壳层或激发态计算。双分子步骤与复合物按 [complex](complex.md) 卡片执行，仅开放以已审阅原子对为约束的采样；通用对接搜索不开放。

借鉴 [ARCHE，arXiv:2609.11147v1](https://arxiv.org/abs/2609.11147v1) 的 Results / “ARCHE System Architecture”（pp. 5–6）与 Methods / “Reasoning–validation circle”（pp. 18–19）：提出竞争假设，用有区分力的计算检验，按矛盾证据修正。下面的 study 记录、可推翻条件及人工签字是本项目的落实方式，不移植论文的自主执行模式。

## 2. 前置条件

已明确科学问题、实验约束和方法依据；区分直接文献先例与类比。读取 [study 模板](../../auto-g16-study/references/study-md-template.md)，记录各物种的身份、原子对应、电荷、多重度和立体化学。未知项写待确认，不猜填；机理假设未签字时只做规划，不推进依赖该假设的计算。

TS 族、关键中间体、复合物必须双路线，可旋转键较多也建议；按
[构象工作流](../../auto-g16-structures/references/conformer-workflow.md)保留路线来源，
读覆盖报告的未匹配项、最低构象和单路线独有低能项。警告时讨论延长 CREST、
增加适用体系的 ETKDG 种子或定向构造约束 CREST（directed），经人确认扩样
后重新出报告。覆盖报告不能证明采样已经完备，也不取代本卡科学判据。

## 3. 输入模板

在仓库外的 `study.md` 填写以下内容，不另建合同或 schema：

```text
机理假设 H1（日期；待人签字）
问题与实验约束：<反应、条件、观察与文献位置>
竞争假设：<H2 的差别；若暂无线索，写尚未检索充分>
步骤：<R → TS1 → I → TS2 → P；逐步写成键/断键原子对>
待算对象：<每个 R/I/P 的构象；每个 TS 的初猜和构象；双向 IRC 与端点极小点>
判别计算：<本轮最能区分 H1/H2 的结构、能垒或其他量>
方法：见计算方案
推翻条件：<如合格双向 IRC 连到其他物种，或统一模型下的能垒与实验时间尺度不相容；写依据和不确定性>
未决问题：<缺结构、方法先例、程序能力等>
签字：<证据清单路径及 SHA-256、日期、签字人、明确确认原意；未确认保持待签>
里程碑后更新：<里程碑、证据位置、支持/反对/不足、保留/修正/放弃、下一步、签字适用对象>
```

计算方案与机理假设一起签字，签字对象包含 study.md 中的方案标识及内容；方案改变时重新签字，保留旧方案和旧签字，不新增里程碑。计算方案签字前不准备依赖它的 Gaussian Attempt。

流程：先写假设及其可推翻条件，运行 `ag review manifest --study <dir>` 生成证据清单，再请人签字并记录清单路径及 SHA-256；按 [Opt+Freq](opt-freq.md)、[TS](ts.md)、[IRC](irc.md) 卡片提出计算；审阅结果；在结构、代表构象集合、最终结果每个里程碑之后更新假设。TS 振动审核和 IRC 端点识别产生新证据时也及时更新。未改变的假设写“保留及理由”，改变步骤、物种、TS 或推翻条件时写修订，重新生成清单并请人签字，旧签字不套用到新假设。

### 物种、条件与比较模型（R02、R03、R05、R06）

以下科学规则提炼自 [旧设计 R02–R14](../../../archive/docs/end-to-end-reaction-computation-workflow.md)
的对应节，仅保留科学内容；用于防止漏计组分、比较不同参考态或只检验一条预设机理。

- **R02：物种与守恒。** 给每个化学身份和原子稳定编号，构象另列；区分
  预催化剂/活性催化剂、游离/缔合/离子对/溶剂化、不同质子化态，以及反应
  条件下产物与后处理产物。逐个基元步骤核对元素/原子和总电荷守恒；涉及
  质子或氢负离子迁移时显式标氢和对应关系。反应式漏画的碱、盐、气体、
  副产物须补入物种清单或说明后处理来源；仍不平衡就记录科学问题，不能
  把总合成反应式直接当成基元反应。
- **R03：实验到模型。** 对每个溶剂、添加剂、反离子、酸碱、气体和试剂，
  逐项选择“显式分子 / 连续介质 / 浓度、压力或化学势项 / 旁观或后处理
  组分 / 未解决”，并写理由。记录实验温度、浓度、催化剂载量及标准态；
  评估离子配对、聚集、质子化、溶剂配位和添加剂结合如何改变活性态。
  显式溶剂分子的个数、位置与自由溶剂参考态必须明确；连续介质并不自动
  描述质子穿梭或特异氢键。不能因添加剂不进入产物就删去它，也不能由
  实验溶剂名直接推定某一种溶剂模型。浓度修正与标准态换算分开记录。
- **R05：竞争机理。** 节点写完整组成、电荷、多重度、立体化学及环境；
  边写基元步骤、成断键/迁移坐标、分子数和可逆性、通道与证据。催化
  研究列出活化、静息态、再生、可能影响结论的离循环/失活态，并核对
  催化循环是否闭合。预催化剂结构不等于活性态；H1/H2 分开保留，排除
  某条竞争机理要写理由，不能把“未画出/未找到 TS”当作排除证据。
- **R06：参考态与动力学模型。** 在计算前选定分离物种或预反应复合物
  零点，逐物种列标准态、实际浓度及显式溶剂/添加剂/反离子的化学势。
  不同原子清单只经配平热力学循环比较。写清构象和催化态能否快速平衡、
  对称性/简并度、步骤可逆性与产物互变。快速平衡假设成立才用 TS 系综；
  慢活性态交换、耦合可逆步骤或产物互变影响结论时转显式动力学网络。
  后续 [profile](profile.md) 按此定义整理能垒和选择性，不能先画图再改零点。

在 `study.md` 中补入以下普通表格即可：

| 物种/基元步骤 | 原子与电荷配平（含未画组分） | 条件组分及模型表示 | 参考态与平衡/动力学假设 | 依据与未决项 |
|---|---|---|---|---|
| <填写> | <填写> | <填写> | <填写> | <填写> |

R04/R07 的科学部分：文献分清直接先例与类比，逐项记录可用的 TS 坐标、
方向和 IRC 证据及缺失项；从示意图不能捏造精确坐标。方法须覆盖基组、

### 候选分类与路径边界

为防止把采样约束、弱缔合或路径连接误当作普通驻点/动力学证据，按对象分流：

| 对象 | 后续路线与证据 |
|---|---|
| 普通极小点候选 | 同身份 DFT Opt+Freq → 零虚频与完整收敛 → 最终去重及适用的 SP/thermo；窗外验证见 SP 卡片 |
| 非共价复合物 | 双分子步骤与复合物按 [complex](complex.md) 卡片执行，仅开放以已审阅原子对为约束的采样；通用对接搜索不开放。按该卡片审阅组分、结合拓扑、分离参考态及低频/缔合熵，再转 Opt+Freq；解离时先确认片段身份、电荷与多重度 |
| 受约束 TS 候选 | 保留约束来源，释放采样约束 → TS 优化/Freq → 一个虚频及方向审核 → 双向 IRC 与端点识别；约束搜索低能不证明鞍点 |
| 扫描初猜 | 沿反应坐标按 [ts](ts.md#初猜来源一维弛豫扫描) 做一维弛豫扫描，记录坐标、范围、步长、冻结项与选点依据；`ag scan-peak` 的内部严格局部极大只是初猜，仍须解除扫描约束、TS 优化、Freq 方向审核及双向 [IRC](irc.md) 端点识别；Gaussian S 行步长须含小数点。两个坐标明显耦合时可按 [ts](ts.md#初猜来源gaussian-二维弛豫扫描) 做 Gaussian 二维弛豫扫描；二维候选须用 `--point i,j` 显式指定，只有列出的候选允许导出，不自动选择。 |
| 方法敏感性 | 关键能垒按 [sp](sp.md#2-前置条件) 在同一几何集合上比较至少两类泛函，保持同基组、溶剂和几何，逐种泛函重建完整能垒；按 [profile](profile.md#3-输入模板) 比较完整参考态与 TS 单点，报告方法改变是否反转排序，结论翻转时在 study.md 写明各方法结果与不稳健性。 |

无势垒的缔合或解离不一定存在普通的一阶鞍点；找不到 TS 不能直接排除该过程，
也不能为填满 profile 的 minimum/ts 交替格式虚构一个 TS。需按体系另行研究
自由能路径、变分或扩散等适用模型，明确当前卡片/工具未覆盖的部分。
IRC 连通不代表真实动力学轨迹；出现分叉迹象时另行研究局部势能面和动力学，
保留替代出口，不能据单条 IRC 推定产物比例或排除所有竞争路径。

## 4. 资源建议

本卡只做本地规划，不占集群资源。先列最小判别计算，按对应卡片估计每个 Attempt 的档位和 walltime；柔性体系要将多个 TS 构象的代价列入，不把所有候选一次性提交。科学假设签字不授权提交。

## 5. 提交前检查清单

- 本卡不提交；假设包含逐步机理、全部所需物种和 TS、可推翻条件及人的签字。
- 原子、电荷守恒与原子对应明确；跨自旋面、碎片电荷不明等超范围问题已记录并停止相关步骤。
- 新计算前展示结构、电荷与多重度、立体化学警告、方法依据、完整 route、档位、walltime、远程目录和输入哈希；提交仍需人点击 Mac 对话框。
- QST2/QST3、父 chk 复用和受支持的扫描输入按 TS/IRC 卡片准备；`ag scan-peak` 只从自身及紧邻点均收敛的内部严格局部极大导出初猜，列出全部局部峰，默认选最高局部峰，可用 `--point` 指定其他局部峰；无峰拒绝导出。气相离子–分子反应中全局最高点常常不是 TS，仍须优化、Freq 方向审核和双向 IRC；端点比较用 `ag irc-compare`。全自动 TS 搜索不在范围；缺能力或证据就暂停依赖步骤。

## 6. 结果判据清单

- `study.md` 中每个机理步骤能对应到待算对象、已获事实和 review；没有计算的对象不写成已验证。
- 每个里程碑后都有假设更新记录；反证和失败保留，区分“数值计算失败”“证据不足”和“合格证据反对假设”。一次 TS 搜索失败不能推翻整条机理。
- 修订后的假设经人重新签字，之后才推进依赖它的工作；未变化的确认对象可沿用既有签字并注明。
- 候选按普通极小点、非共价复合物、受约束 TS 分别安排后续；无鞍点过程与分叉疑点明确列出研究边界，不把缺 TS 或 IRC 连通当成动力学结论。
- TS 恰好一个虚频且方向正确仍只是候选；IRC 必须两个方向都走完并识别端点后才能声称验证。仅一条可行路径不能证明唯一机理。

## 7. 常见失败与处理

证据与假设冲突时，先查数值收敛、结构和比较方法是否一致；有效反证则修正或放弃原假设，列出替代假设、最小判别计算并重新请人签字。需要补算时提出新 Attempt，等人确认。

能力缺失时在 study“当前阻塞”写对应的结构、提交、解析、科学审阅或环境原因及所缺能力/证据；已知结果仍可整理，但不绕过缺口。真实环境意外先停止报告，按 [异常说明](../../auto-g16-study/references/unknown-and-failures.md)处理。

## 8. 常见坑

知识衔接：[GKB-0431、GKB-0441：TS 与路径证据](../../auto-g16-gaussian-learning-library/references/core-job-types.md)。

- 把方法失败当作机理反证，或忽略与实验不相容的结果，都会误导下一步；记录证据有效性，再改假设。来源：ARCHE Methods / “Reasoning–validation circle”，pp. 18–19。
- 人签机理假设表示同意检验该假设，不等于认可结论，也不替代结构、代表构象集合、最终结果三个签字。
- `ag graph --study <study_dir>` 只展示 Attempt 的父子来源关系；它不证明化学连接关系，也不表示机理因果关系。IRC 端点比较用 `ag irc-compare`，其结果仍需科学审阅。

### F4：研究核时估算与记录

改编自 `archive/skills/auto-g16-rtwin-pbs/references/protocol-rigor.md` 的
资源与科学精度分开、分阶段列成本，以及
`archive/docs/end-to-end-reaction-computation-workflow.md` R07/R10/R11 的
依赖与候选覆盖经验；`archive/docs/resource-monitor-efficiency-migration.md`
仅保留估算与实际占用需区分的经验，不恢复旧资源审批或迁移流程。

估算 `阶段核时 = Σ_j 作业数_j × 申请核数_j × 预计墙钟小时_j`；
首批未知耗时给范围并注明依据，不把申请 walltime 当实际耗时。
同一作业中的 Opt、Freq/CalcFC 只记一次总耗时；并发缩短日历时间但不减少核时。

| 阶段 | 数量与耗时怎么估 | 首批校准点 |
|---|---|---|
| 构象采样与筛选 | 分物种/家族、采样路线与种子计数；本地 RDKit 成本另列，CREST/xTB 集群核时单列 | 同体系首批采样耗时、生成及保留数，含窗外验证与去重后需优化的数量 |
| 极小点 Opt+Freq 与单点 | 保留代表数 × 每代表 Opt+Freq/精化 SP 次数；不同规模与方法分组 | 实测 SCF、优化步与 Freq 总耗时；筛选 SP 和最终 SP 不漏记、不混计 |
| TS 搜索与 Freq | 每通道/家族的初猜数 × 每次成本；有限的失败/新 Attempt 情景另估 | 初始 Hessian、每优化步、末次 Freq 的耗时；未获批准的重做只列情景，不自动执行 |
| IRC 与端点 | 对每个获准验证的 TS 分列双向点数/每点成本，另计两个端点优化/Freq | 起始力常数和校正耗时、实测路径长度；不能只预算一个方向 |

首批完成后逐阶段用相近规模、相同方法和档位的实测范围修订剩余核时，
保留原估计、修订日期与原因；方法敏感性和补采样单列，未覆盖对象仍注明。
增加核数的加速比须实测，不能假定线性；失败作业消耗也计实际，未知耗时不填零。

按负责人 2026-10-16 的安排，SCNet 不设置核时额度拦截：
`budget_core_hours` 可省略，Slurm 台账仍记录本机 ag 作业的预留/结算；
不设额度时不因预计消费超额而拒绝。当前代码若显式配置该字段仍检查上限，
这不是取消全部安全检查：核数、绑定、台账一致性和人工提交确认仍有效。
预留为核数 × 申请 walltime，结算按调度记录的实际资源/时长；UNKNOWN 不猜测释放。
台账不代表平台余额，也不含外部作业消费；平台余额和计费规则由负责人自己查看。
study 记录格式见 [模板的 F4](../../auto-g16-study/references/study-md-template.md#f4研究核时估算与实绩)。
