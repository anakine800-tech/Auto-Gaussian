# 失败诊断

## 1. 适用范围

主族闭壳层计算的本地结果诊断，产物是修改建议。真实环境意外先报告并停止操作；本卡不触发恢复、重传、取消或新提交。

为防止无依据地叠加昂贵参数、或把数值收敛当成化学正确，借鉴 [arXiv:2609.13357v1](https://arxiv.org/html/2609.13357v1) §II.5 “Decision ladder”：先处理执行/数值问题，再判断目标态及模型，最后检查与先例的一致性。本卡将这一顺序改写为 Gaussian 主族计算的低成本优先阶梯；不照搬 ORCA CASSCF 的活性空间、轨道旋转或论文中无须人确认的重试规则。

## 2. 前置条件

已有 Attempt 输入、状态、已取回的输出及 `facts.json`；读当前 `review.md` 和 study。缺日志时说明诊断局限，不为了填齐事实自行处理异常。`unknown` / `failed_presubmit` 交给 [异常说明](../../auto-g16-study/references/unknown-and-failures.md)，只报告、等人决定；不能套用阶梯创建替代 Attempt 来绕过不确定性。

## 3. 输入模板

按 `termination`、`error_hint`、`opt_converged`、`freq_step_converged`、`n_imag` 和已有输出定位问题。 `error_hint` 优先给出具体原因及日志全局行号；“TS 曲率不符”需核对负本征值与期望值，未知 L9999 只提示“优化未完成（原因见日志）”，不能据此直接增加步数。结合最后 80–120 行与更早收敛记录；大小写归一理解 `l9999` / `L9999`，不把链接号当唯一病因。在 review 写：

```text
现象、Attempt 与输出位置：<事实；缺证据的部分>
诊断：<有证据的原因或明确标为假设>
适用级别：<第几级；更低级为何不适用/无效>
上次修改与结果：<同一问题已改几次；两次仍失败就交给人>
本次最小改变：<一个有依据的参数/几何/资源变化；不叠加无关修改>
预期代价与退出条件：<如何判定解决；未解决时下一步由人决定>
新 Attempt 建议：<原输入与新输入的差别；尚未准备/提交>
```

没有通用重启 route。人决定继续后，按对应卡片准备新输入和 `ag prepare`，用已有 `--parent <failed_id> --relation retry_of` 记录来源；频率阶段重优化可用 `reoptimized_from`。跨 Attempt 复用 chk 使用 `ag prepare --parent-chk <parent_id>:<chk文件名>` 并按 TS/IRC 卡片核对适用性，不能盲用 Restart/Guess=Read；原 Attempt 和输出保留。

### 电子态与 Stable 诊断

长键、断键、强电荷转移、SCF 有多个解或近简并迹象时，即使 SCF 收敛，
也须审查电子态，防止在错误电子态上接受能量、频率和路径。记录可疑几何、
SCF 解的能量/占据与已有自旋证据，向人提出独立 `Stable` 诊断作业；
沿用被诊断几何、方法、基组、溶剂、电荷/多重度，核对波函数来源。
若需检查特定父 SCF 解，按父 chk 规则声明并审阅 `Guess=Read`；重新生成
的波函数不能冒称就是原解。诊断仍须新 Attempt 和人的提交确认。

T30 的 `facts.json` 字段 `wavefunction_stability` 只报告当前作业最后一条诊断：
`stable`、`internal_instability`、`rhf_to_uhf` 或 `unknown`；
`wavefunction_stability_line` 保存原文行（缺失可为 null），须回查原日志。
字段缺失、unknown 或只见正常终止都不是稳定证据；Link1 后不能沿用前段结论。
stable 仅表示对所测扰动稳定，不证明全局最低电子态或单参考方法适用。
出现 internal_instability/rhf_to_uhf 时暂停科学接受并报告；若需非限制性
或多参考方法，明确标注“超出当前闭壳层卡片范围”，交给人另定方法。
不得把 `Stable=Opt` 机械地加到所有计算里：它会尝试重优化波函数且可能
转为非限制性；即使最终打印 stable，也须重审实际电子态及原几何/频率的适用性。
关键词依据：[Gaussian Stable 手册转载](https://conflex.co.jp/gaussian_support/stable.php)。

## 4. 资源建议

诊断先做本地只读核验，不占集群核数。阶梯按通常改动幅度和成本排列，实际代价必须估计；不同级不是必须各跑一次。有明确 walltime/内存证据时可直接提出对应资源级，说明为何低级无关，不为走完阶梯浪费计算。任何新计算均待人确认。

资源档位为 simple（8 核 / 12 GB）、general（22 核 / 50 GB）、complex（44 核 / 120 GB）；Gaussian 内存仍不超过档位的 85%，核数受当前配置约束。

## 5. 提交前检查清单

- 本卡不提交。排队不算失败；UNKNOWN、SSH 报错、哈希不一致或真实作业异常结束先停止报告，不能靠升级阶梯继续执行。
- 提议使用的几何确实存在且身份/立体化学经核对；父 chk、QST 或额外输入段须符合当前 prepare 支持的形式，缺证据就记录具体阻塞。
- 每次只提出有证据支持的最小改变，列明科学影响与成本。同一问题修了两次仍未解决，直接到最后一级，不继续逐级试跑。
- 人同意后仍要展示结构、电荷、多重度、立体警告、方法依据、完整 route、资源、walltime、目录与输入哈希，由人点击 Mac 提交对话框。

## 6. 结果判据清单

- 诊断引用事实与位置；缺失或有歧义处不补写成功，原因不确定时明确标“假设”。
- 进入、操作、退出条件完整，升级有更低级不适用/失败的证据；只记录建议，不声称已解决。
- 新结果到来后重新应用原计算卡片的全部判据；数值收敛不代表结构、目标态或机理正确。
- 极小点任一虚频都需解释；TS 则须恰好一个且方向正确，不能把预期 TS 虚频当作失败消除。IRC 仍须双向完成及端点识别。
- 已触发电子态疑点时记录 Stable 诊断提议、T30 状态及原文证据；未知不视为稳定，非限制性/多参考需求标明超出闭壳层范围。
- 原输入、状态、输出保留，新 Attempt 不能重用旧提交声明；UNKNOWN 不进入重算流程。

## 7. 常见失败与处理

下列是建议阶梯，不是执行循环。只读诊断发现可接受结果就回原卡片审阅，不为升级而计算；每一级的退出条件都需要真实新证据才能判定达成。

### 作业被强杀

先 `ag status <attempt>`：PBS 需 interrupted、至少两次相隔 5 分钟的不活跃观察，输出大小/mtime 不变且无退出回执；Slurm 需 sacct 终态且 squeue 无此作业。UNKNOWN、仍运行或无法核实都停止，不据文件不变推断作业结束。
满足后 `ag fetch <attempt> --incomplete`，只取确认存在的声明输出；核对独立记录的缺失项，再 `ag facts <attempt>`。权限/SSH/哈希错误立即报告，保留 `.partial`，不手工补文件；不能再用普通 fetch 或 --add-missing 升级这份取回记录。
由人决定用父 chk 接续（新 Attempt，RCFC 或 Guess=Read）、从最后几何重新开始，或延长 walltime 重来。RCFC/ReadFC 坐标必须用 `final_input.xyz` 并通过既有取向校验；只在能导出时使用，缺失则停止。有效不完整取回记录允许 interrupted 父 chk，父子同集群、manifest 绑定、复制前后哈希和独占创建检查全部保留。
被杀时 chk 可能未写完整；安全复制不保证 Gaussian 能读取，也不保证有可用 Hessian。提交仍须逐个展示完整摘要并由人点击 Mac 确认；不自动接续或重提。不完整结果禁止进入 thermo/profile，最终结果须按新 Attempt 的完整证据重新审阅。

### 第 1 级：纠正已定位的输入错误

知识卡片：GKB-0430。

**进入条件**：已有输出如 `End of file in ZSymb`，且能定位普通单结构输入格式或抄录错误。**具体操作**：核对空行、标题、坐标段、电荷多重度及完整 route；只改与已签对象不符的抄录，科学设定不明则交给人。QST2/QST3 按 TS 卡片核对多个结构块和原子映射；超出已支持语法时停止，不试凑分隔行。**退出条件**：新输入符合已审阅结构且后续输出证实按预期进入计算；其他问题按证据分类。提出新 Attempt，等人确认

### 第 2 级：最小数值收敛调整

知识卡片：GKB-0411、GKB-0422。

**进入条件**：身份与输入无误，`l502` / SCF 记录显示不收敛，或优化平稳接近收敛但达到步数上限。**具体操作**：先核对电荷、多重度、近接触和能量/梯度趋势；仅差步数时提出有限增加 SCF MaxCycle 或 Opt MaxCycles；SCF 振荡则考虑 XQC 并说明新增代价，不同时更换方法。**退出条件**：SCF/优化的相应收敛证据出现，且原卡片其他判据仍待逐项审阅；停滞时不能无限加步数。提出新 Attempt，等人确认

### 第 3 级：曲率、优化精度与积分设置

知识卡片：GKB-0422、GKB-0451。

**进入条件**：第 2 级不适用或无效，优化停滞（包括 `l9999`），或极小点 `freq_step_converged=false`。**具体操作**：读取末次频率收敛表、`Non-Optimized Parameters` 及最终几何；身份不变且为频率阶段位移问题时，提出同方法、显式最终坐标的 `Opt=CalcFC Freq`，relation 为 `reoptimized_from`。有数值误差依据时再提出 Tight 优化/更细积分网格；说明 Hessian 与更细网格的成本。TS 必须保留 TS 优化设置，不能套普通 Opt 消掉反应虚频。**退出条件**：Opt 和频率阶段收敛、完整频率及对应极小点/TS 判据通过；旧失败结果不进入热化学集合。提出新 Attempt，等人确认

### 第 4 级：重新审阅几何与构象

知识卡片：GKB-0431、GKB-0441。

**进入条件**：数值问题已排查，但极小点有虚频、TS 虚频数或方向不符，或结构/立体构型变化。**具体操作**：检查完整模式位移及原子映射；极小点可提出沿虚频小扰动后再优化，TS 则重选有依据的初猜或柔性构象。极小点有小虚频时，可用 `ag mode-review` 导出的位移几何提出新 Attempt，由人确认，命令本身不准备或提交计算。小于 50 cm⁻¹ 的负频不直接置零；身份变化或 IRC 连到其他物种时更新机理假设并请人重签。**退出条件**：目标身份和构象经确认，新结果满足对应振动判据；涉及路径仍须双向 IRC 与端点识别，缺能力或证据时记录具体缺口。提出新 Attempt，等人确认

### 第 5 级：有证据的资源或方法升级

**进入条件**：明确 walltime/内存不足，或低级调整无法解释同组能量离群、错误目标态及与可靠先例的显著冲突。**具体操作**：walltime 按已完成进度提出延长；内存按实际错误提出合适档位与合规 `%mem`，不复制多个同任务。模型问题先核对同组成、同方法、同能量类型比较，再查直接先例，向人提出方法/溶剂/模型变化及整组可比性影响。开壳层/多参考问题超范围，不套论文的 CASSCF 参数。**退出条件**：人明确选择可支持的方案，且新结果通过全部科学判据、资源瓶颈或差异已解释；仍矛盾则交给人。提出新 Attempt，等人确认

### 第 6 级：停下，交给人判断

**进入条件**：同一问题已修两次仍失败、原因/身份/自旋无法确定、需要不支持能力，或前述级别无法给出有依据的方案；可从任意一级直接进入。**具体操作**：停止计算操作，保留证据，列出已试变化、未决问题和具体能力缺口，在 study“当前阻塞”写明类别与原因；请人决定修订目标、补证据或停止。**退出条件**：人提供明确新方向且缺口解决；否则保持停止，不能默认继续。只有人决定继续且方案明确后才提出新 Attempt，等人确认

## 8. 常见坑

知识衔接：[GKB-0411、GKB-0422、GKB-0451、GKB-0441：SCF、优化、虚频及 IRC 排障](../../auto-g16-gaussian-learning-library/references/core-job-types.md)。

- 决策阶梯提供诊断顺序而非自动重试程序。论文 §II.5 的 A/B 对应执行/SCF，D/F/H 提醒目标态、先例一致性与完整成功判据；这里的 Gaussian 级别及人工停止规则是项目改写，不移植论文 §II.3 的自主重试策略。
- 排队不是启动失败；日志正常终止与优化驻点分别核对。来源：`archive/skills/auto-g16-rtwin-pbs/references/environment-and-failures.md`。
- 输出截断不能证明频率完成；一个虚频还需方向审核，TS 需双向 IRC 与端点识别；断开片段的近自由运动不等于普通单分子极小点。来源：[archive/skills/auto-g16-ts-irc/SKILL.md](../../../archive/skills/auto-g16-ts-irc/SKILL.md)。
- 从最终几何加 `Opt=CalcFC Freq` 曾解决频率阶段位移未收敛；仅为已有实例，不是所有虚频的通用修复。新旧 Attempt 用 `reoptimized_from` 关联，不能自动重提。来源：study `butane-l1-20261013`，`lessons/05-calcfc-reoptimization.md`。
