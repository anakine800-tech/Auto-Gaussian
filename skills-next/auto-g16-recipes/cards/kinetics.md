# 动力学解释：能垒、可逆性、选择性与隧穿

## 1. 适用范围

解释主族闭壳层、同一势能面上已审阅的自由能剖面：Eyring 时间尺度、
正逆反应竞争、快速平衡条件下的产物通量，以及 Wigner 隧穿的适用边界。
这是本地解释卡，不新增计算程序；数值换算不证明机理或预测精度。

改编自 `archive/docs/end-to-end-reaction-computation-workflow.md` 的 R06/R13/R14，
以及 `archive/skills/auto-g16-asymmetric-catalysis/references/candidate-and-selectivity-protocol.md`
第 5、7、9 节：只保留共同参考态、系综求和、覆盖与不确定性，不沿用旧流程。

## 2. 前置条件

按 [profile](profile.md) 核对极小点、TS 方向、双向 IRC 与端点证据；
未验证的路径只能报告候选模型估计。整组温度、标准态、方法、溶剂、组分
和原子/电荷计量一致。热化学按 [thermo](thermo.md)，不能用电子能垒替代 ΔG‡。
先写明基元步骤、参考盆地、实验时间及浓度是否已知，构象/中间体是否快交换，
产物是否会逆反应、互变或被后续选择性捕获。缺少这些信息时保留模型限定。

## 3. 输入模板

### Eyring：ΔG‡、k 与半衰期

一级不可逆基元步骤、传递系数 κ = 1 时：

```text
k = (k_B T/h) exp(−ΔG‡/RT)                 [s⁻¹]
t_1/2 = ln(2)/k                           [s]
ΔG‡ = RT ln[(k_B T/h)/k]
ΔG‡ = RT ln[(k_B T/h) t_1/2 / ln(2)]
```

κ 非 1 时把前因子乘以 κ；不能既修改能垒又重复乘同一校正。
采用 k_B = 1.380649×10⁻²³ J/K、h = 6.62607015×10⁻³⁴ J·s，
R = 8.31446261815324/4184 kcal·mol⁻¹·K⁻¹；298.15 K 时 RT ≈ 0.592485 kcal/mol。
下表是这些公式的独立算术示例，不是论文实验数据或适用性阈值。

| ΔG‡ (kcal/mol) | k (s⁻¹) | t_1/2 |
|---|---|---|
| 15 | 6.28327×10¹ | 0.0110316 s |
| 18 | 3.97348×10⁻¹ | 1.74444 s |
| 20 | 1.35882×10⁻² | 51.0112 s |
| 22 | 4.64676×10⁻⁴ | 24.8613 min |
| 24 | 1.58906×10⁻⁵ | 12.1167 h |
| 26 | 5.43413×10⁻⁷ | 14.7632 d |
| 28 | 1.85832×10⁻⁸ | 431.710 d |

**准一级的浓度条件。** 对 A + B → P，B 大量过量且近似恒定时，
以 c° = 1 mol/L 的分离物种标准自由能定义 ΔG‡°：
`k₂ = (κ k_B T/h) exp(−ΔG‡°/RT)/c°`，单位 L·mol⁻¹·s⁻¹；
`k_obs = k₂[B]`，此时才有 `t_1/2 = ln(2)/k_obs`。
表中的速率可视为 [B] = c° 时的准一级值；实际浓度未知时不补填。
若 B 会明显消耗、存在多步催化或耦合可逆过程，须按相应速率方程分析，
不能直接套一级半衰期。已在自由能中加入同一活度效应时，不再乘一次浓度因子。

**工具入口。** `ag profile <study_dir>/analyses/reaction.json --json`
生成的各步 `forward_kinetics` / `reverse_kinetics` 含 `k_s-1`、`half_life_s`
及自然对数；实现为 `ag/src/ag/profile.py` 的 `eyring`。
目前按 κ = 1 换算，缔合时仅为标准态浓度的准一级近似；不会替你拟合
实际浓度动力学，也没有独立的 kinetics 子命令。反算公式供本地核验。
双分子低能垒的扩散控制提示与 ΔH‡、−TΔS‡ 分解见 profile；
触发提示时先审阅扩散、缔合熵和参考态，不把 TST 数字当作可靠绝对速率。

### 可逆性：逆能垒要与反应时间一起读

在同一零点上，`ΔG‡rev = G_TS − G_P`；不能把正向能垒当逆能垒。
例如约 24 kcal/mol 对应 298.15 K 下约 12 h 的一级逆反应半衰期，
只表示小时量级值得检查逆反应，不是“可逆”或“不可逆”的结论。
在忽略回流的单向近似下，时间 t 内发生逆反应的比例为 `1 − exp(−k_rev t)`；
比较 `k_rev t` 是否很小，再结合正向通量、平衡、产物移除及后续捕获。
简单 A ⇌ P 的松弛时间由 `1/(k_f + k_rev)` 决定，并非孤立逆反应半衰期。
分离反应物系综零点与复合物零点必须区分；`G_TS − G_complex` 单列为
“复合物内禀能垒”，不能与分离反应物能垒混排。

### 选择性：ΔΔG‡、er、ee 与 dr

在共同反应物参考态、相同前因子及 κ 下，令
`ΔΔG‡ = G‡eff,minor − G‡eff,major ≥ 0`：

```text
r = major/minor = exp(ΔΔG‡/RT)
ΔΔG‡ = RT ln(r)
ee (%) = 100 (r − 1)/(r + 1)
r = (100 + ee)/(100 − ee)                 [以正的 ee 大小表示]
```

298.15 K 的下表同样为公式复算值。er 用于一对对映体，dr 用于所定义的
非对映产物对；多于两个产物时报告各分支归一化比例，不把 dr 叫作 ee。
100% ee 的有限测量不能反推出无穷大精确能垒，须考虑检测限。

| ΔΔG‡ (kcal/mol) | er 或两产物 dr（major:minor） | ee（仅对映体，%） |
|---|---|---|
| 0 | 1:1 | 0 |
| 0.5 | 2.32543:1 | 39.8573 |
| 1.0 | 5.40761:1 | 68.7871 |
| 1.5 | 12.5750:1 | 85.2670 |
| 2.0 | 29.2422:1 | 93.3867 |
| 3.0 | 158.130:1 | 98.7432 |

Curtin–Hammett 要求反应物构象/中间体间互变快于各自生成产物，形成同一
快速平衡池，且简单产物比模型要求产物生成近似不可逆、无后续互变或
差别捕获。少量构象也可能通过低 TS 主导通量，不能只从最低反应物构象出发。
慢交换时按可快交换的盆地分别处理，以初始布居、交换和各生成/逆反应速率
构建动力学网络；这些网络拟合/积分当前不由 profile 提供，须记录能力缺口。

通道 c 中先跨搜索家族去重，再汇总保留的全部可比 TS：

```text
W_c = Σ_i g_i exp(−ΔG‡_ci/RT)
ΔG‡eff,c = −RT ln(W_c)
fraction_c = W_c / Σ_b W_b
```

g_i 只包含尚未显式枚举的物理权重；共同参考盆地的自由能需统一。
profile 的 `selectivity` 是输入 JSON 字段，不是单独命令：

```json
{"selectivity": [{"id": "products", "products": {
  "R": [{"species": "ts_r1"}, {"species": "ts_r2", "paths": 2}],
  "S": [{"species": "ts_s1"}]
}, "perturb_kcal": 1.0}]}
```

完整物种定义见 profile 卡片。每个 TS 物种内的构象简并度已进入 `ensemble_G`，
`paths` 只计尚未枚举的等价路径，不能再乘一次构象权重或旋转对称数 σ。
工具按产物分支加总通量；`effective_barrier_relative_kcal` 以最占优产物
为零，不是相对于反应物的绝对有效能垒。`ddG_barrier_kcal = G_eff(b) − G_eff(a)`，
`ratio_a_over_b = W_a/W_b`；`ee_percent` 按输入第一标签减第二标签，可能为负。
只有标签确为对映产物才解释为 ee。统一组分的共同参考态会在比例中消去，
但不同参考盆地、不同浓度或不平衡组分不能靠此消去。

### 误差口径与 S7 隧穿

298.15 K 下 1 kcal/mol 的能垒差对应 `exp(1/RT) = 5.40761` 倍速率差，
约为 5 倍。这是指数放大关系，不是 DFT 误差保证。方法、溶剂化、低频和
遗漏 TS 的误差可使 ΔΔG‡ 变号；保留排序与敏感性区间，不按 ee 小数位比较优劣。
`perturb_kcal` 一次只扰动一个 TS 物种，不是联合误差界或统计置信区间。
按已签方案做方法、构象遗漏及 50/100/150 cm⁻¹ 低频敏感性；不挑有利的一档。

Wigner 的高温、局部抛物线势垒近似：

```text
x = h c |ν̃‡|/(k_B T)
κ_W = 1 + x²/24
k_W = κ_W k_TST
```

ν̃‡ 是唯一且方向正确的虚频的波数绝对值；以 cm⁻¹ 输入时 c 用 cm/s。
这只是二阶小修正，要求 x 足够小、势垒顶部可近似抛物线；
“虚频不太大”必须连同温度判断，没有跨温度通用的波数合格线。
不能因公式总能给出正数就用于大校正、深隧穿或强非谐势垒。
涉及 H 转移且虚频很大、低温、显著同位素效应或非一维路径时，需要审阅
Eckart 势垒、变分 TST 与多维隧穿或 instanton 等更高级处理的适用性；
当前 ag 不支持这些校正，也不自动应用 Wigner。将其写成能力缺口；
仅做手动 Wigner 估计时另存公式、频率来源、单位、温度与适用性说明，
不改原 profile 数值，不把此估计称作已验证的隧穿速率。

## 4. 资源建议

本地换算不占集群核时。需要补 TS、互变能垒或更高级隧穿模型时，先列证据
缺口和预计代价，再由人决定；本卡没有自动补算或重试操作。

## 5. 提交前检查清单

- 本卡不提交；能量单位、温度、标准态、参考盆地和反应级数明确。
- 时间尺度的浓度条件明确；未知实际浓度不修正，速率不能冒称实验值。
- TS 及产物分支来源可追溯，互变/可逆性假设、权重和已包含修正已核对。
- Wigner 若用于独立估计，记录唯一虚频及方向、x 和小修正适用性；超范围留缺口。

## 6. 结果判据清单

- 能垒、正逆 k、半衰期互算一致，给出一级/准一级条件及单位；与实验时间一起解释。
- 各产物的全部保留 TS 去重后汇总；报告 er/dr/ee 的标签与符号约定、缺失通道和覆盖局限。
- 快交换、共同参考态与产物生成假设有依据；不成立时不把 Boltzmann 比例称作预测产物比。
- 报告能量扰动、方法/低频/构象敏感性；数值稳定不等于模型正确。
- 无隧穿校正的工具输出与独立 Wigner 估计分开；高级动力学能力缺口明确。
- 在 study 引用本地分析，按既有流程先生成证据清单再请求最终结果签字；工具换算不代签。

## 7. 常见失败与处理

结果与实验时间/选择性不符时先核对单位、正逆方向、反应级数、浓度和
参考零点，再查 TS 覆盖与方法敏感性；不能用调整 κ 强行拟合。
可逆/慢交换证据推翻简单模型时保留旧分析并说明其范围，提出动力学网络需求。
浮点溢出时保留工具的自然对数，null 不是零速率或无穷大确定半衰期。
需新计算时转相应卡片；真实异常按 [异常说明](../../auto-g16-study/references/unknown-and-failures.md)。

## 8. 常见坑

知识衔接：[GKB-0512：溶液自由能组合](../../auto-g16-gaussian-learning-library/references/advanced-properties.md)。

- 一级半衰期不是催化反应完成时间；逆能垒的量级换算不是可逆性结论。
- 一个最低 TS 不能代表整个产物分支；不同参考盆地的局部能垒不能直接求和。
- ee 接近 100% 不表示误差小；实验符合不证明唯一机理，dr 也不是 ee。
- Wigner 不修复错误 TS、错误热化学或势垒形状，不能无限外推到低温/大虚频。
