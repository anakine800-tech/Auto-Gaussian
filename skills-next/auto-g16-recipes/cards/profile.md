# 反应能量曲线：ag profile

## 1. 适用范围

适用于主族闭壳层、同一势能面的已审阅路径。把同一 study 中不同物种的有限构象系综 G 按计量组合为一条有序反应路径。纯本地确定性分析，不查询配置、不连接服务器、不修改 Attempt 或已有 thermo。计算前由 LLM 写 profile 定义、人审阅物种身份、路径、构象平衡和循环闭合假设；工具不推断机理，不证明构象覆盖完整。

科学规则来自 `archive/docs/end-to-end-reaction-computation-workflow.md` 的 R02、R06、R13、R14；仅采用守恒、共同参考态、热化学口径和不确定性分析，不沿用旧工作流。分子式纯函数改写来源见 `ag/_profile_sources.py` 文件头。

## 2. 前置条件

用于“已验证剖面”的极小点须通过 [Opt+Freq](opt-freq.md)，TS 须通过 [TS](ts.md) 方向审核及 [IRC](irc.md) 双向完成/端点识别。缺验证的态只能作为未验证候选报告，不能称作已验证边。标准态、浓度和参考盆地按 [reaction-plan](reaction-plan.md) 审阅；程序的可读 review 检查不替代这些科学要求。

每个物种独立生成 `ag thermo` 输出，并保留其各行引用的 study/attempts 下的 `facts.json`、`final.xyz`。读入的事实必须对应生成该 thermo 时的最终结果；改变输出、事实或热化学设置后，重新生成 thermo。不要手工改能量列。程序重算构象分配函数以核对 `ensemble_G`，不用 `weighted_mean_G`。

也可直接引用一组已取回完整 Gaussian 日志的 Attempt（需 manifest）；profile 用同版本 GoodVibes 4.3.0 在内存中计算 qRRHO，不写 facts/thermo。TS 用此通路，因为现有 `ag thermo` 只接受极小值。虚频不反转、不取绝对值；GoodVibes 不把反应坐标计入稳定振动配分函数。

TS 每个构象必须有 `n_imag=1`，其 `review.md` 中保留具体方向审阅依据，并由审阅者加入两行明确结论：

```text
profile_review: pass
imaginary_mode_matches: true
```

这两行只是现有科学 review 的可读结论，不能由程序根据虚频数量自动补写。方向错误或审阅不通过写 `fail` / `false`，profile 拒绝。TS 作为路径验证的证据还需双向 IRC 及端点识别；本工具的审阅检查不等于 IRC 验证。minimum 状态的所有物种须 `n_imag=0`。

## 3. 输入模板

将 JSON 放在 `study/analyses/reaction.json`，所有文件引用相对于该 analyses 目录；Attempt 用本 study 中的目录名。示例只是结构模板，替换引用为真实本地结果后才能运行：

```json
{
  "reference": "R",
  "temperature_K": 298.15,
  "standard_state": "1M",
  "catalytic_cycle": false,
  "species": {
    "cat": {"thermo": "thermo-cat.json"},
    "sub": {"thermo": "thermo-sub.json"},
    "complex_ts": {
      "attempts": [
        {"attempt_id": "study-010-ts-c01", "degeneracy": 1},
        {"attempt_id": "study-011-ts-c02", "degeneracy": 1}
      ]
    },
    "product_complex": {
      "thermo": "thermo-product.json",
      "single_conformer_reason": "已审阅的刚性产物模型；本次只保留一个代表"
    }
  },
  "states": [
    {"id": "R", "kind": "minimum", "species": {"cat": 1, "sub": 1}},
    {"id": "TS", "kind": "ts", "species": {"complex_ts": 1}},
    {"id": "P", "kind": "minimum", "species": {"product_complex": 1}}
  ]
}
```

`states` 按前进方向交替排列 minimum、ts、minimum，可接续任意多步。每步由相邻三态定义；无势垒的缔合或解离不一定存在普通的一阶鞍点，不能为满足输入交替格式虚构 TS 或零能垒；本命令不表达这种边，须另行研究自由能/动力学模型并注明能力缺口。计量系数为正整数（分数计量先整体倍增），重复出现的自由物种需在各状态明确列出。元素和电荷取自实际几何与 facts；可在物种中额外填 `formula`、`charge`，工具会交叉核对；公式只接受如 `C4H10`、`CH3COOH` 的显式写法，不支持括号、点盐或同位素标记。

单构象必须逐物种提供非空 `single_conformer_reason`；即便简并度大于 1，只算了一个代表也要说明。构象归属、物理简并度和分子身份的判断仍由人负责，元素组成相同不证明是同一个物种。

复合方案在每个 Attempt 中加 `"spc_attempt_id": "study-012-sp-c01"`；所有物种都使用相同的频率层与单点层，不混用有/无单点修正。方法、基组、色散和溶剂从本地 Gaussian route 提取，区分两个层级。`Gen/GenECP/ChkBasis`、自定义 ECP、IOp、SCRF=Read 等缺少可确定完整定义的输入会明确报错；不能当作默认方法放过。溶液 route 必须写出模型与溶剂，如 `SCRF=(SMD,Solvent=Water)`；等价方法的拼写差异可能需要核实后统一来源。

直接 Attempt 默认采用当前 thermo 的设置：298.15 K、1 M、Grimme 熵/Head-Gordon 焓修正、各 100 cm⁻¹、频率/ZPE 缩放 1、global inertia。可用顶层 `thermo_settings` 覆盖已有设置名；与 thermo 表混用时，未指定设置会继承第一份表，仍逐物种核对全部设置。如果指定温度与来源不符，必须重算热化学，不能仅更改 RT。

`standard_state` 指输出目标标准态（`1M` 默认，或 `1atm`），与来源 thermo 的浓度分别记录。已有 GoodVibes 1 M 修正不会再加一次。每物种修正后再乘计量；例如两个自由分子合成一个复合物，标准态贡献的分子数变化是 −1。

显式自由溶剂浓度用顶层字段，例如：

```json
{"explicit_solvent_concentrations_M": {"water": 55.5}}
```

`water` 必须是 species 中实际参与状态的独立极小值物种。只修正独立自由溶剂的化学势，不对复合物里已结合的水再额外修正。298.15 K 下 `RT ln(55.5/1) = +2.379646 kcal/mol`；消耗一个自由水时，相对能垒/反应自由能相应降低这个量。水的实际浓度由人根据体系确定，不自动套用纯水值。

```sh
ag profile <study_dir>/analyses/reaction.json --perturb 1.0 --json
```

输出为同一 analyses 下 `reaction-profile.json` 与 `reaction-profile.md`。可用 `--name reaction-profile-v2` 指定新文件名；任一目标已存在则整个操作报错，不覆盖。所有科学校验完成后才写两个输出文件。

**保留的科学解释与扩展模型（不是本命令新增输出）**

在 study 的本地分析中逐项记录，下表是科学整理模板，不是 CLI 文件格式：

| 物种/构象/通道 | 化学计量与显式组分 | 最终 E_SP | 频率层级 E、ZPE、热焓/熵及 G 修正 | 低频/标准态处理 | 简并度与系综 G | 来源及验证状态 |
|---|---|---|---|---|---|---|
| <填写> | <填写> | <单位> | <单位与公式> | <温度与已包含项> | <定义与单位> | <填写> |

**R13：组成自由能。** 对每个几何采用
`G_i = E_SP,i + (G_qRRHO,low,i − E_elec,low,i)`；分别保留原始频率层级的
零点能、热能、焓和 Gibbs 修正、最终单点电子能与低频处理。
括号中的 G 若已含标准态换算，就不重复添加。标准态修正按每个独立
物种计数，反应修正为各物种修正的化学计量和。实际浓度另以
`μ_i = G_i° + RT ln(a_i)` 表示，理想稀溶液可用 `a_i = c_i/c°`；
纯溶剂、气体及非理想体系须声明相应活度/压力模型，不能一律代入 1 M。

构象系综可写成 `G_ens = G_min − RT ln Σ_i d_i exp[−(G_i−G_min)/RT]`。
分别记录构象简并度 d_i、旋转对称数 σ_i 和等价反应路径数 m_ci 及各自来源；
σ_i 已在转动热化学中计入，不再充当 d_i；路径数不写入 thermo 的 degeneracy。
同一化学盆地单独汇总，说明对称性、简并度及其来源；已逐个列出的
等价结构不能再次乘同一简并度。TS 反应坐标的虚频不作普通稳定振动
参与热配分函数；须核实工具的 TS 热化学处理，不能把极小点布居工具
直接用于鞍点集合。

SMD 下 H/S 分项只是当前 RRHO/qRRHO 与单点替换模型的审计分项，
不能解释为实验溶液的焓熵分解；连续介质溶剂化自由能没有在此独立拆成
溶剂化焓与熵。仅改变热化学温度会重算分子热修正和相应标准态项，
不等于包含溶剂化自由能的温度依赖；温度效应结论须说明固定溶剂模型的近似。
布居只代表所选集合内归一化结果。构象互变相对实验/反应时间尺度很慢时，
按可快速互变的盆地分别处理，盆地间权重需初始条件或动力学依据，
不能把所有构象直接汇成一个全局平衡布居。

对每条具有已审阅 TS 的基元边 R ⇌ P，通过组成相同的 TS 定义：

```text
ΔG‡_forward = G_TS − Σ_r ν_r G_r
ΔG‡_reverse = G_TS − Σ_p ν_p G_p
ΔG_rxn     = Σ_p ν_p G_p − Σ_r ν_r G_r
ΔG‡_forward − ΔG‡_reverse = ΔG_rxn
```

ν 为各侧正的化学计量数；需计入相应旁观组分或化学势项来配平零点。
预反应复合物内禀能垒与从分离物种起算的表观能垒分开命名，不能混排。
每条边展示实际代入式及单位；缺物种、显式组分不配平、混方法或混参考态
就列为缺项，不插值补成完整曲线。这防止漂亮剖面掩盖不可比的能量。

**R14：连接到可观测量。** 根据 R06 选最简单且有依据的模型：

- 快速平衡、不可逆分流等假设适用时，汇总每个产物通道的全部可比 TS，
  `W_c = Σ_i m_ci d_i exp(−ΔG‡_ci/RT)`，m_ci 仅计未被显式 TS 枚举或 d_i 计入的等价路径，
  已逐路径列出时 m_ci=1；这些额外权重只在科学分析中记录，本命令不计算通道概率。共用参考态/前因子时
  `P_c = W_c/Σ_c W_c`。两通道有符号 `ee = (P_R−P_S)/(P_R+P_S)`，
  报百分数乘 100%；dr/区域比按对应通道总权重求比，先定义标签。
  各反应物状态权重应由公共零点或显式布居引入，不能重复计权。
- 对单分子基元步骤，TST 可用 `k = κ k_B T/h · exp(−ΔG‡/RT)`；
  写明传输系数 κ 假设；相同前因子/κ 时，298.15 K 下能垒差 1 kcal/mol
  约对应 5.4 倍速率比（exp(1/RT)），说明小能差可显著影响预测。多分子标准态速率常数的单位、浓度因子和
  分子数须另行推导，不把此单分子式直接叫二级速率常数。
- 催化循环可在假设成立时用 energetic-span；多步可逆反应、缓慢催化态
  交换、浓度依赖或产物互变影响结论时需显式动力学/微观动力学网络。
  本命令未实现通道选择性、速率常数和微观动力学；需要时记录缺口，不能由最高的一根能垒直接推断
  实验速率或由两个孤立 TS 推断 ee。

输出应包括每个通道的覆盖、简并度、排除理由和仍缺的合理候选。
分别检查构象遗漏/逐一移除候选、能量扰动、溶剂、低频处理、标准态、
催化态布居与竞争机理；扰动范围按研究所需精度和方法证据选择。
关键能垒按[方法敏感性](../../auto-g16-study/references/acceptance-methods.md)
至少比较两类泛函的完整参考态与 TS 单点，报告一个合理遗漏候选或方法
改变是否足以反转排序。自旋态影响若超出闭壳层范围，记录范围缺口。

IRC 连通证明的是所审阅势能面的路径连接，不代表真实动力学轨迹或产物比例；
出现路径分叉迹象时另行研究局部势能面及适用的动力学，不能凭单条 IRC 排除分支。
普通极小点、非共价复合物和受约束 TS 候选按
[reaction-plan 的分类后续路线](reaction-plan.md#候选分类与路径边界)分别处理后再决定能否进入本工具。

## 4. 资源建议

纯本地；无集群核数或 walltime。读取已有 thermo 表不需要重新算量化结果；直接 Attempt 通路需要已安装 GoodVibes/cclib。无需提交、服务器配置或系统确认对话框。

## 5. 提交前检查清单

- 每态显式列全旁观分子、对离子、显式溶剂与副产物，元素和电荷相对参考态一致，不能用能量零点隐藏不守恒。
- 单点层、频率层、温度、来源标准态、低频处理一致；数据缺失报错，不用默认值补齐来源证据。
- 分别核对构象系综、简并度、单代表原因，避免异构体误归入同一构象集合或等价构象重复计数。
- TS review 的方向结论真实可追溯；minimum 无虚频。
- 若 `catalytic_cycle=true`，人核对这是一次完整周转，首末状态包括同一再生催化剂及反应物/产物。末态是下一周转的首个中间体加净反应化学势，不能误把某个未闭合中间体当末态。程序不从结构自动识别循环闭合。

## 6. 结果判据清单

- 表格输出各状态 ΔG，以及每步 `G_TS−G_R`、`G_TS−G_P`、`G_P−G_R`，JSON/Markdown 均列出公式。
- `G_state=Σν_s G_ensemble,s`；`G_ensemble=−RT ln Σd_i exp(−G_i/RT)`。
- 标准态每物种 `RT ln(C_target/C_source)`；`C_1atm=1/(R_L_atm T)`。显式溶剂再加 `RT ln(c/C_target)`，两项单独显示。
- 循环按 [Kozuch–Shaik, Acc. Chem. Res. 2011, eq 9, DOI:10.1021/ar1000956](https://doi.org/10.1021/ar1000956)：遍历所有 TS/中间体对；TS 在中间体之后用 `G_TS−G_I`，之前用 `G_TS−G_I+ΔG_cycle`，取最大值为 δE。末态作为下一圈首态，不重复加入 TDI 候选。输出 TDTS、TDI、所有配对及并列最大值，不用全图最高点减最低点替代。
- 这是给定单一循环的能量跨度近似，不输出完整速率或证明某一个步骤决速；非放能循环只报告形式上的跨度，不推断正向 TOF。
- `--perturb x` 对每个 TS **状态**逐个加、减 x kcal/mol，保留其他状态不动，报告 TDTS/TDI 配对是否变化（包括并列）。这是逐项敏感性，不是所有误差组合的全局稳健性证明。非循环仅比较最大局部正向能垒，不称作动力学决速态。

**研究结论的进一步审阅（本命令不计算通道概率或 KIE）**

- 逐边给出正反能垒与反应自由能，满足上述差值关系，说明公共参考态。
- 数值可追溯到每个物种与构象，缺项未静默删除；相应通道的有限覆盖明确。
- 动力学模型与平衡/可逆性假设一致；速率单位、选择性标签、温度、
  浓度和统计权重可核对。预测的归一化通道概率之和为 1。
- `study.md` 逐项列目标量、所需精度、实验速率/温度/选择性/KIE 与
  对照结论。KIE 须有同一模型下的同位素热化学/速率证据，不能用普通
  能垒直接声称算出了 KIE；没有数据或能力明确写缺失。
- SMD 焓熵分项、温度依赖近似、d_i/σ_i/路径数分工及慢互变盆地均已说明；无鞍点的边和分叉疑点另列，不以 IRC 连通声称真实动力学已验证。
- 若方法改变使结论翻转，必须在 `study.md` 写明各方法结果与不稳健性。
  结论可写“暂定”“无法区分”或“在所述机理、方法、模型和覆盖下得到支持”。
  符合实验 ee 或速率不能证明唯一机理。

## 7. 常见失败与处理

不守恒先修正状态组成；方法混用或温度不一致需统一并重算上游热化学；缺 review 或虚频方向不对需科学审阅。失败时不输出“部分有效”的完整曲线。缺计算只能提出后续计划，本工具不会新建或提交 Attempt。

输出已存在时换新名字保留旧结果。只有系综热力学及给定路径的数值比较，不代表整个 study 已完成或机理已验证。

## 8. 常见坑

知识衔接：[GKB-0611、GKB-0630：能量跨度与能量图](../../auto-g16-gaussian-learning-library/references/research-workflow.md)。

- ΔΔG‡ 的符号连同通道顺序说明，少一个低能 TS 就可能反转选择性。
- 采样次数不是物理简并度；与实验相符仍可能存在未排除机理。

- 最大局部能垒、最高 TS 与能量跨度不是同一量；跨周转项必须包含 ΔG_cycle。
- 自由溶剂已按浓度计入后不能再对反应加同一项；显式水不是连续介质模型。
- 终点重复计为新的 TDI 会虚增跨度；切换参考态不能改变能垒或跨度。
- 增加的检查分别防止缺旁观物种造成假反应能、混协议造成假排序、把零/多虚频当 TS、混用加权平均 G、重复浓度修正和覆盖旧分析等具体错误，不引入通用合同或审批流程。

数值回归采用 Lv 等人模型循环的图 2（[Nat. Commun. 13, 36, DOI:10.1038/s41467-021-27813-4](https://doi.org/10.1038/s41467-021-27813-4)）：未加括号数值的 TDI −9.3、TDTS 23.9，跨度 33.2 kcal/mol；括号数值为 −8.5、23.7，跨度 32.2 kcal/mol。仅转录图中标有数值的点，不编造没有数值标注的 model_TS3。这是文献数值算术回归，不将文献方法当作本工具 Gaussian 输入通路的完整验收。
