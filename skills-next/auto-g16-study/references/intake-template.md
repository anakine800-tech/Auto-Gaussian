# 开题包模板

把本模板各节填入私有 study 的 `study.md`，文献明细和讨论按
[literature-record.md](literature-record.md)、[discussion-record.md](discussion-record.md)
记录；材料较多时放在该 study 的 `analyses/` 并在 `study.md` 引用。
模板是填写指引，不是可执行输入；不自动判断立体通道，不自动生成 Attempt。
未知填“未知”并写影响，不用空白或猜测补齐。

- 开题包版本、日期：<填写；修订保留旧版本、原因及旧签字>
- 保密级别：是否已发表 <是/否/部分/未知>；级别 <公开/组内/课题保密>；能否进公开仓库或 PR <是/否/仅指定脱敏内容及范围>。发布前先读此行，未知按不公开处理。
- 当前主会话与交接：<沿用 study.md 的主会话记录>
- 分工：开发机独立研究会话核对结构、检索文献，不连集群；监督方用问答讨论并作科学判断建议；负责人决定并签字。定稿后交给 study 所在电脑的计算会话，记录交接后由该会话推进 prepare，同一时间只有一个主会话。

## 4. 原子对应（atoms.csv）

在私有 study 保存 `atoms.csv`，表中一行是同一原子在一个物种/结构文件中的出现。
必填列如下；没有值时写“未知/不适用及原因”，不编造对应。

| 列名 | 含义 |
|---|---|
| atom_id | 跨结构保留的稳定原子 ID；不能用随文件重排而变化的索引代替 |
| species_id | 对应第 3 节的物种 ID |
| structure_file | study 内的结构文件相对位置 |
| atom_index_1based | 该文件的原子序号，从 1 开始；转换 RDKit 的零基索引时明确加一 |
| element | 元素；有同位素时另注明 |
| reaction_role | 成键 / 断键 / 转移 / 立体中心 / 其他；可多项 |
| mapping_source | 原件编号/人工映射/RDKit 最大公共子结构及版本、参数、候选歧义 |
| review_status | 待核对 / 已确认 / 有歧义 |
| reviewer_date | 人工核对人及日期；待确认时明确写待确认 |
| notes | 映射依据、歧义或不适用原因 |

RDKit 最大公共子结构只能辅助生成初稿，对称原子可能有多组映射。
同一结构文件的序号不能重复，元素与文件一致；相同 atom_id 才表示跨物种对应。
反应涉及的氢须显式编号，不只列重原子。成键/断键/转移原子和立体中心由人逐个确认；
记录每一步的成键、断键原子 ID 对。换文件或重排原子后重新核对对应，不能沿用旧索引猜测。

## 5. 立体通道表

由人提出并确认通道。主键是“空间构型 → 产物构型”：空间构型用稳定原子 ID
及明确的进攻面/相对取向定义，产物构型绑定产物结构及其已核实构型。
通道编号只作简称，不能只用中间体的 R/S 当主键。

| 通道编号 | 空间构型 → 产物构型（主键） | 原子对应及结构依据 | 中间体 CIP（逐中心） | 产物 CIP（逐中心） | 纳入/不纳入及理由 | 确认人、日期/未决项 |
|---|---|---|---|---|---|---|
| <填写> | <明确进攻面/相对取向 → 指定产物构型> | <atoms.csv 与结构位置> | <填写> | <填写> | <填写> | <填写> |

校验：同一主键不重复计作独立通道；同一通道的不同旋转异构/构象另列成员，
不能凭文件名推断对应，也不能仅因 CIP 相同而合并。镜像关系及是否可合并由人结合体系确认。
两套 CIP 必须分别计算；连通性或取代基优先级改变可使 R/S 标签改变，即使映射中心的空间排列未翻转。
反之，标签相同也不能单独证明空间排列保持。产物未定时标待确认，不自动补齐或宣称通道覆盖完整。

**虚构小分子示例（仅说明 CIP，不主张反应可行性）：** 假定四面体中心连接
F、H、CH₂OH、CH₂Cl，随后 CH₂OH 支链变为 CH₂Br，中心映射的空间排列保持。
以中心及相邻碳的稳定 ID 跟踪取向，不能把离去 O 和新 Br 当作同一个原子。

| 通道编号 | 空间构型 → 产物构型 | 中间体 CIP | 产物 CIP |
|---|---|---|---|
| A | 取向甲 → 构型甲（中心空间排列保持） | R | S |
| B | 取向乙 → 构型乙（甲的镜像） | S | R |

取向甲的观察约定：H 朝远离观察者方向时，F → CH₂Cl → CH₂OH 顺时针；
将该支链改为 CH₂Br 后保持中心相对排列。原优先级为 F > CH₂Cl > CH₂OH > H，
新优先级为 F > CH₂Br > CH₂Cl > H，故 R 变为 S；取向乙为镜像，S 变为 R。
示例的两对形式结构已用 RDKit 核对，实际课题仍须对其自身结构逐中心重算。

构象家族另列，不增加通道数；例如 s-cis/s-trans、转子分组须用原子 ID 和二面角约定定义，不能只按文件名分类。

|---|---|---|---|
| <填写> | <填写> | <填写> | <填写> |
