# 经验条目

当实际问题被解决或人指出错误后，在当前 study 的 `lessons/` 写草稿；同一问题补充已有草稿即可。不直接修改 Skill 文件，人审阅后再通过单独的卡片修改纳入。

```markdown
# <简短经验标题>
- 日期：<日期>
- 现象：<实际观察；相关 Attempt 和本地输出位置>
- 原因：<证据支持的原因；尚未证实则标为假设>
- 处理：<做过的动作及结果；未执行建议要区分>
- 建议修改：<卡片名 / 第几节 / 建议文字>
- 适用边界：<何时有用、何时不能套用>
- 人的审阅：待审阅
```

提议增加检查时，写清它防止的是哪个已发生或很可能发生的事故。公开卡片只保留通用经验与来源，不带研究数据、连接信息或真实路径。
